# 首页技能模版接口与本地技能调整

更新日期：2026-10-31

本期客户端直接读取 `resources/quick/skills/manifest.json` 和同目录技能包，不启用 mock、不请求下述运营接口，也不读取运营缓存。以下接口定义留作后续接入。

## 1. 独立首页运营接口

接口名称：获取首页技能模版运营配置。

```http
GET /client_operations/homepage/skill_templates?version=1.7.27
Authorization: Bearer <现有 API Key>
```

后台独立配置首页运营条目，不复用技能广场列表接口。原技能广场接口和字段保持不变。

### 输入参数

Query 参数：`version`（string，必填），当前客户端版本号，取自 `app.getVersion()`，例如 `1.7.27`。无请求体，鉴权沿用现有 API Key。

返回全部运营配置，不分页；客户端过滤已删除、版本不兼容的条目，按 `order` 升序取前 3 个展示，同序按 `folderName` 升序。

## 2. 本地原有技能需要调整的点

1. **需要模版输入的技能，在 `SKILL.md` 同级增加 `example.json`**，随版本 ZIP 发布。不需要模版能力的老技能不强制调整，保持原行为。
2. **示例素材只写远程 URL，不打入 ZIP**；视频、图片、音频分别定义分组，每组严格限定对应类型。
3. **默认素材满足分组数量限制**，允许用户不替换、原样发送。
4. **提示词以“使用@技能名 技能”开头**，名称与实际可调用技能一致；`inputs.model` 填有效模型 ID。
5. **新文件使用 `url`，客户端兼容旧 `uri`**；封面使用 `display_info.cover_url`，原作品链接使用 `display_info.web_share`。
6. **参数或技能逻辑变化时提高技能 `version`**，发布新的 ZIP 地址；首页运营配置与包内参数绑定同一版本。
7. 首页做同款使用隐藏技能副本执行，不加入技能成员列表；不改写用户已安装的技能副本。客户端发送给 Agent 的用户消息只含提示词和素材。

### 2.3 真实模板与约定格式的差异及调整点

- `inputs.prompt` 当前没有“使用@技能名 技能”前缀；发布时在原提示词前补上 `使用@一张图生成餐厅引流团购视频 技能，`，避免客户端重复追加。
- 原文件的 `parameters.model.default` 是 `qwen-3.8-flash`，`inputs.model` 是 `qwen3.8-flash`；按实际模型列表统一为同一个有效 ID，客户端优先读取 `inputs.model`，缺失时才取默认值。
- 原提示词含 `<你的门店/菜品图路径>`，发送时需引用实际所附主图，避免保留未替换占位符；默认示例图可原样发送。
- 原文件 `display_info.estimated_usage` 是数值 `600`，保留兼容；客户端展示时转成文本，独立运营接口仍按 string 输出。不擅自把该数值解释为扣费承诺。
- `display_info` 没有结果预览视频地址，需要在运营配置中补充；不能用原作品网页地址代替视频播放地址。
- `author`、`comment_count`、`share_count` 及 `role`、`bytes`、`md5_8`、`continuity_group` 等扩展字段可保留，本期页面不要求新增对应运营接口字段。图片的 `duration_seconds` 不参与视频／音频时长校验。

`folder_name` 对应运营接口的 `folderName`，`skill_name` 是实际技能调用名，两者不要混用。封面和原作品链接以 `display_info` 内字段为准；已有顶层同义字段可保留兼容。

该模板仅包含 `images.hero`，最少和最多均为 1 张。视频模板使用 `parameters.videos` / `inputs.videos`（`video_groups` / `video`），音频使用 `parameters.audios` / `inputs.audios`（`audio_groups` / `audio`）；不需要的媒体类型可省略。

首页展示以独立运营接口为准，表单以包内 `example.json` 为准。运营配置和包更新下载就绪后，下次启动整体生效。
