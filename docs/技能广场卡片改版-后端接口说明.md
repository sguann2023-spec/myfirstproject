# 技能广场卡片改版：后端接口说明

更新日期：2026-11-04。本文定义新版广场接口约定。客户端已接入独立服务，并先使用开发 mock 联调；后端可按本文实现。

## 1. 获取新版广场模板列表

```http
GET /skill_template_marketplace/templates?limit=20&offset=0&app_version=1.7.27
Authorization: Bearer <现有 API Key>
```

### 请求参数

无请求体；Query 参数如下：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `limit` | integer | 否 | 每页数量，默认 20，范围 1–50 |
| `offset` | integer | 否 | 已加载条目数，默认 0，必须大于等于 0 |
| `app_version` | string | 是 | 当前客户端版本，如 `1.7.27`；用于后端过滤不兼容模板，不是技能包版本 |

### 返回示例

仅使用列表接口，不新增详情接口；点击“做同款”直接使用列表返回的版本和下载地址安装。以下地址为结构示例，后端返回实际可访问的 HTTPS 地址。

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": "template_10001",
      "name": "微缩世界化妆品带货",
      "folder_name": "market-template-micro-world-product",
      "version": "1.0.0",
      "likes_count": 31000,
      "web_share": "https://www.douyin.com/video/7693603351920938259",
      "preview": {
        "type": "video",
        "url": "https://example.com/templates/10001/preview.mp4",
        "cover_url": "https://example.com/templates/10001/cover.jpg",
        "width": 1080,
        "height": 1920
      },
      "package": {
        "download_url": "https://example.com/templates/10001/1.0.0/skill.zip"
      }
    }
  ],
  "total": 36
}
```

### 返回字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `code` | integer | 是 | 成功为 0，失败为非 0 |
| `message` | string | 是 | 成功说明或错误信息 |
| `data` | array | 是 | 当前页模板；没有数据返回 `[]` |
| `total` | integer | 是 | 已上架且兼容当前客户端的模板总数，分页前统计 |
| `data[].id` | string | 是 | 新版模板的稳定唯一 ID，用于去重，不复用旧版技能 ID |
| `data[].name` | string | 是 | 技能名称，也作为埋点属性 `skill_name` 的值 |
| `data[].folder_name` | string | 是 | 安装到 `GlobalSkills` 的英文目录名；只能是单级目录，不含斜杠等路径字符 |
| `data[].version` | string | 是 | 技能包版本，使用 SemVer，如 `1.0.0`；必须与包内 `.version` 一致 |
| `data[].likes_count` | integer | 是 | 非负原始点赞数量，如 31000；不要返回 `3.1万`、`1千+` 等格式化文本 |
| `data[].web_share` | string | 是 | “查看”打开的抖音原作品地址，必须是 HTTPS URL |
| `data[].preview.type` | string | 是 | `video` 或 `image` |
| `data[].preview.url` | string | 是 | 视频或图片预览的 HTTPS 地址；视频悬浮播放、大预览均使用此地址 |
| `data[].preview.cover_url` | string | 是 | 卡片静态封面 HTTPS 地址；图片模板可与 `preview.url` 相同 |
| `data[].preview.width` / `height` | integer | 是 | 预览素材的真实宽高，均大于 0；封面采用相同比例，用于瀑布流预先布局 |
| `data[].package.download_url` | string | 是 | 该版本完整技能 ZIP 的 HTTPS 下载地址；列表直接返回，做同款不再请求旧版详情接口 |

## 2. 列表与技能包约定

- 后端只返回已上架、兼容 `app_version`、可预览且可做同款的模板；按运营排序升序，同序按稳定 ID 排序。
- `offset` 超出总数时正常返回 `data: []`，不是报错。客户端使用 `offset + data.length < total` 判断是否还有下一页。
- 技能 ZIP 根目录包含 `folder_name/` 文件夹，其内必须有 `SKILL.md`、`example.json`、`.version`，以及执行所需脚本、引用等完整文件。
- 沿用目前的 `example.json` 格式，`inputs.model`、提示词和素材分组仍由它定义；列表不重复返回整份模板配置。
- `name` 与技能包中 `SKILL.md` 的名称、`example.json.skill_name` 保持一致，`example.json.folder_name` 与 `folder_name` 一致。
- 同一个 `id`、`version` 对应的技能包不可变更；修改模板配置或技能文件须升级版本。签名下载地址需留足有效期，过期后重新获取列表可取得有效地址。
- 点击做同款后安装到 `GlobalSkills`；同目录已安装版本较旧才替换，相同或更高版本不替换，无法确认已安装版本时保留。

## 3. 新旧数据隔离

- 新接口使用独立的模板数据集合，不向旧接口混入新模板，也不向新接口返回旧技能；可以复用底层代码，但筛选、运营配置及总数独立。
- 新旧条目使用独立 ID、安装目录名，避免安装新版模板时覆盖旧技能；同一新版模板升级时保持 ID、目录名稳定，只增加技能包版本。
- 客户端单独维护新版列表缓存，接口失败或返回空数据时不回退旧版列表。
- 只移除广场的搜索和“我的技能”入口；聊天右侧技能管理继续保留，安装后的新版模板可在其中管理。
- 首页现有预装模板继续读取 `resources/quick/skills`，不受本接口影响。

## 4. 本期不需要新增的接口

不新增搜索、我的技能列表、模板详情、点赞写入接口。“查看”使用 `web_share` 在客户端内网页预览；“做同款”直接使用本接口的技能包地址；爱心数量仅展示，不执行点赞。

鉴权失败使用 HTTP 401/403，参数错误使用 HTTP 400，服务异常使用 HTTP 5xx；失败响应统一为 `{ "code": 非0整数, "message": "可读错误信息" }`。

## 5. 客户端 Mock 联调

- 开发环境默认使用 `resources/skill-template-marketplace/mock/` 下的 6 个独立条目，每页 3 个，包含图片与视频。不会请求旧技能接口或新版模板接口。
- 关闭 mock：开发启动时设置 `VITE_SKILL_TEMPLATE_MARKETPLACE_MOCK=0`，即请求本文的新接口；正式安装包始终关闭 mock，且不包含 mock 技能包。
- mock 使用演示数量和既有示例素材，视频不保证是对应模板的生成结果。点击做同款会真正安装独立示例技能，但不自动发送任务；发送后仍调用真实 Agent。
- mock 技能与首页预装技能使用独立目录和名称，不修改旧版列表、首页清单或首页技能包。
