# 教育知识讲解口播模板

这是一个鲜黄亮蓝风格的教育知识讲解口播视频草稿技能。它以主播口播视频为主线，默认做去气口，输出 1080x1920 剪映草稿；适合知识点拆解、学习方法讲解、学科科普、课程干货分享等教育类口播。素材是可选项，不再强制用户提供。

## 输入限制

- 必须有口播视频和用户本次外部传入的 VectCut API Key。
- 素材可不传；不传素材时，全程只展示去气口后的口播视频。
- 素材可传 1 到 50 条，支持视频或图片；有素材时才做素材分析和语义穿插。
- API Key 必须使用用户本次消息里传入的原始值，并通过本次执行输入显式传入；不能读取历史缓存值。

## 默认流程

1. 规范化输入，确认口播视频和本次 API Key。缺任一项时先询问，不创建草稿。
2. 提取口播视频音频，并默认用 `effect_mode=llm_vad` 做 ASR。
3. 生成唯一 `timeline.json`。口播视频、口播音频、字幕都必须使用这同一份去气口时间线。
4. 如果 ASR 词级结果里存在句子文本之外的尾部溢出词，例如半个“呃/嗯/老”或重复起头，收紧该句后置 padding，避免把口癖带入口播音频。
5. 如果没有素材，生成单段全口播分镜：`0 -> target_duration_ms` 全部使用 `talking_head`。
6. 如果有素材，先分析素材内容，再让模型按文案匹配素材；视频素材走 `video_detail`，图片素材走本地图片理解，不把图片提交给远端 `video_detail`。教育知识讲解场景下，优先匹配板书课件、知识结构图、题目示例、课堂片段、实验演示或关键概念示意图等素材。
7. 穿插素材片段同一素材最多使用 1 次；视频素材展示 1 到 3 秒，图片素材展示 1 到 2 秒；素材不匹配时回到口播画面，不硬插。
8. 添加字幕时不调用智能字幕接口，全部使用 `/cut_jianying/add_text` 手动写入 `manual_subtitle` 轨道。
9. 根据口播文案总结两行开场标题，写入独立标题轨道，展示 3 秒；标题规则见 `references/title.md`。
10. 识别文案中的 3 到 4 字排比短语，最多 4 个，按 ASR 词级首尾时间调用排比文字预设；规则见 `references/parallel-presets.md`。
11. 排比预设接管的短语不再重复出现在普通字幕；短语位于长句中间时，按词级时间拆出短语前后的普通字幕。
12. 字幕写入后添加口播视频分段、可选素材分段、口播音频分段和 BGM。
13. 查询最终草稿结构并返回草稿 ID、草稿链接、去气口时长、标题、排比预设数量、字幕数量、素材穿插数量和关键校验结论。

## 字幕样式

普通字幕必须使用：

```json
{
  "font": "江户招牌",
  "font_color": "#FFFFFF",
  "font_size": 12,
  "border_color": "#3488F3",
  "border_width": 30,
  "transform_y_px": -900,
  "fixed_width": 0.65
}
```

关键词高亮必须在同一条 `add_text` 请求里使用 `text_styles`，不要额外新增关键词文字层。关键词样式：

```json
{
  "style": {
    "color": "#ffdd00",
    "size": 12
  },
  "border": {
    "color": "#3488F3",
    "width": 30,
    "alpha": 1.0
  }
}
```

`text_styles[].start` 和 `text_styles[].end` 使用字幕字符串的字符下标；只标记真实出现在字幕文本里的关键词，避免范围越界或重叠。

字幕入场动画按条随机，但整体保持三档近似均衡：

- `1/3` 不加动画：`intro_animation=""`、`intro_duration=0.0`。
- `1/3` 使用 `渐显`：`intro_animation="渐显"`、`intro_duration=0.35`。
- `1/3` 使用 `打字机_III`：`intro_animation="打字机_III"`、`intro_duration=0.45`。

执行时把每条字幕的动画选择保存到 `subtitle_intro_animations.json`，用于复盘比例和排查。

标题使用大模型根据口播文案总结两行内容：第一行 4 到 6 个字，第二行 6 到 8 个字，标题不得混入普通字幕轨道。

## 执行入口

使用技能内置流程生成剪映草稿。输入包括口播视频、VectCut API Key、可选主题和可选素材列表；多个素材按用户提供顺序处理，无素材时全程使用口播画面。

图片素材按图片类型处理，视频素材按视频类型处理。图片理解优先使用可用的本地能力或用户提供的预分析结果；视频素材使用视频分析结果做文案匹配。教育知识讲解内容优先围绕知识概念、解题步骤、课堂场景、图表示意和案例演示做语义穿插。对外交付内容只保留草稿和任务关键信息，不包含执行环境信息。

## 交付

只交付剪映草稿链接，不渲染成片视频。最终答复需要包含：

- 草稿 ID 和草稿链接。
- ASR 模式。
- `removed_duration_ms` 去气口删减时长。
- `talking_head_chunks` 和 `speech_audio_chunks` 是否一致。
- 字幕数量、字幕重叠数量。
- 素材穿插数量、图片素材数量、视频素材数量；无素材时说明全程口播。
