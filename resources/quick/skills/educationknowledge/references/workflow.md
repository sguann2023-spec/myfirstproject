# 执行流程

1. 确认口播视频和本次 VectCut API Key。
2. 查询口播视频和可选视频素材时长；图片素材不查视频时长。
3. 提取口播音频，默认用 `effect_mode=llm_vad` 做 ASR。
4. 基于 ASR 生成唯一 `timeline.json`，口播视频、口播音频、字幕都复用这份去气口时间线。
5. 若没有素材，直接生成单段 `talking_head` 分镜覆盖完整时间轴。
6. 若有素材，逐条分析素材内容：视频素材走 `video_detail`，图片素材走本地图片理解。让 LLM 只在和文案强匹配的位置穿插素材；视频每段 1 到 3 秒，图片每段 1 到 2 秒，同一素材最多使用一次。
7. 写入口播视频分段和可选素材分段。视频素材使用 `add_video`，图片素材使用 `add_image`；口播视频必须使用 `timeline.json.chunks`，不能整段覆盖。
8. 写入字幕。全部使用 `/cut_jianying/add_text`，不调用智能字幕；关键词高亮使用 `text_styles`。
9. 写入口播音频分段，分段数量和边界必须与口播视频一致。
10. 查询最终草稿结构，校验字幕无重叠、无智能字幕、音视频 chunk 一致、素材数量符合计划。

失败处理：

- 素材分析或分镜失败时，有素材则走本地兜底短切素材；图片兜底展示 1 到 2 秒，视频兜底展示 1 到 3 秒；无素材则全程口播。
- 字幕重叠时回到字幕规范化，不创建备用字幕轨。
- 素材不匹配时宁可不插素材，不硬插。
