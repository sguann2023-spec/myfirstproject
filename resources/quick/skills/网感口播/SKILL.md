# 通用口播高级红模板

用这个技能把口播视频做成高级红风格竖屏草稿。模板包含开头标题、中文/英文双语字幕、关键词红色弹出、少量转场、一次视频缩放、提示音和背景音乐。

## 基本原则

- 默认画布为竖屏 `1080x1920`。
- 必须使用用户提交的视频作为主画面；视频可以是公网 URL，也可以是本地视频路径。如果用户只给文案而没有视频，必须先要求用户补充视频链接或上传视频，不能创建草稿。
- 默认开启去气口，让主视频、字幕、转场、缩放和音频按处理后的时间轴对齐。
- 原始 ASR 句子是字幕和效果的唯一基准；不能合并相邻 ASR 句子，不能删除、重排或改写原句。
- 样式默认值和可覆盖字段见 `references/style_config.md`。
- 语义规划由模型完成；标题、字幕拆分、双语翻译、关键词、转场、缩放和提示音规则见 `references/llm-prompts.md`。
- 时间轴、工作流提交和异常处理细节见 `references/workflow.md`。

## 输入

从用户请求里整理这些信息：

- `video_url` / `video_urls`：与 `local_video/local_videos` 二选一必填，公网可访问的口播视频地址；可以是一个，也可以是多个。
- `local_video` / `local_videos`：与 `video_url/video_urls` 二选一必填，本地视频路径；可以是一个，也可以是多个。用户给本地路径时，先上传为临时视频链接，再进入后续流程。
- `text_content` / `text_contents`：可选，用户提供的校正文案，只用于 ASR 校对和语义规划参考；单条文案可用于全部视频，多条文案按视频顺序一一对应。文案不能替代视频，没有视频时不能继续。
- `cover_url`：可选，草稿封面地址。
- `draft_name`：可选，用户自定义草稿名。
- `remove_silence`：可选，去气口选项，默认开启。
- `style_config`：可选，只覆盖用户明确指定的标题、字幕、关键词、动画、转场、缩放或音频参数。

公网视频和本地视频至少需要一个；两者都没有时必须停止，向用户索要视频链接或本地视频上传，不创建草稿，不调用 ASR，不做语义规划，不执行 workflow。不要把 API Key、请求头或完整服务回包写进最终回复。

## 执行步骤

1. 准备参数。先检查是否有 `video_url/video_urls/local_video/local_videos`；如果没有，立即要求用户提交视频链接或上传视频并停止。通过检查后，再统一整理成视频列表，并确认草稿名、是否开启去气口、用户是否覆盖了模板参数。
2. 处理本地视频。如果列表里有本地视频路径，先用脚本上传到 VectCut 临时存储，取得临时视频链接。临时链接有效期有限，后续 ASR 和写入主视频都使用这个链接。
3. 逐个处理视频。每个视频独立执行后续步骤，互不复用 ASR、语义规划、草稿 ID 或草稿链接。
4. 查询视频时长。无法取得正数时长时按源码口径使用 `60.0` 秒兜底，并记录该兜底状态。
5. 识别字幕。用脚本提交 ASR 任务并等待完成；默认使用去气口识别。去气口识别没有有效句子时，用普通识别重试一次。
6. 整理时间轴。把 ASR 句子整理成独立字幕句，每句保留原文、源视频开始结束时间、草稿目标开始结束时间和词级时间。开启去气口时主视频会被切成多段连续写入，不能让草稿时间轴出现空白。
7. 做一次语义规划。模型直接根据 `references/llm-prompts.md` 里的规则，一次生成标题、字幕排版、英文字幕、关键词、转场、缩放和提示音规划。规划时不能合并相邻 ASR 句子，不能改写原文。
8. 校验规划结果。检查标题不超过模板限制，字幕能按 `source_index` 回拼 ASR 原文，三种转场各最多一次，缩放最多一处，关键词必须来自当前句。失败时按参考文件重试一次，仍失败则记录当前视频失败原因。
9. 组装并执行工作流。把创建草稿、添加主视频片段、标题、双语字幕、关键词弹出、转场、缩放关键帧、提示音和 BGM 全部放进一个 workflow，一次性提交执行，减少串行接口调用。
10. 查询草稿并校验。工作流成功后读取返回的草稿 ID 和草稿链接，再查询草稿结构，确认主视频、标题、双语字幕、关键词弹出、转场、缩放、提示音和 BGM 都已写入。
11. 返回结果。无论处理 1 个还是多个视频，都返回 `drafts` 列表。每项包含视频来源、处理状态、草稿 ID、草稿链接、时间轴时长、ASR 句数和字幕数量；只有用户明确要求预览视频时才渲染视频。

## 样式口径

- 标题默认显示在开头 `min(5.0, timeline_duration)` 秒内，使用高级红双行标题样式。
- 中文字幕默认使用“思源粗宋”，英文字幕使用 `Poppins_Bold`。
- 1-7 个有效字符用普通单行字幕；8-12 个有效字符用上下分层字幕；超过 12 个有效字符只在当前 ASR 句内部拆分。
- 所有上下分层字幕必须共用固定轨道：上行中文 `yimei_layered_top`、下行中文 `yimei_layered_bottom`、上行英文 `yimei_layered_top_en`、下行英文 `yimei_layered_bottom_en`；不要为每条长句创建 `yimei_layered_00_top`、`yimei_layered_01_top` 这类独立轨道。
- 每条字幕以 `0.5` 概率使用 `打字机_I`，持续 `0.2` 秒。
- 关键词是红色文字弹出层，不是贴纸；必须按源码方式用全角空格占位叠加，不能把关键词作为独立自由位置文字层。只有字幕命中打字机动画时才创建关键词弹出层。
- 转场只允许 `向右`、`向左`、`竖向模糊`，每种最多一次。
- 视频缩放最多一处，缩放值为 `1.2`。
- BGM 从固定列表随机选择并循环铺满目标时间轴。

## 脚本使用

接口调用都通过 `scripts/koubo_1f9c_api.py` 完成。运行时显式传入 API Key，例如：

```bash
python scripts/koubo_1f9c_api.py --api-key "$VECTCUT_API_KEY" upload-video --file "/absolute/path/to/koubo.mp4"
python scripts/koubo_1f9c_api.py --api-key "$VECTCUT_API_KEY" duration --url "https://example.com/koubo.mp4"
python scripts/koubo_1f9c_api.py --api-key "$VECTCUT_API_KEY" asr submit-and-wait --url "https://example.com/koubo.mp4" --effect-mode llm_vad
python scripts/koubo_1f9c_api.py --api-key "$VECTCUT_API_KEY" execute-workflow --workflow-file "/tmp/koubo_1f9c_workflow.json"
python scripts/koubo_1f9c_api.py --api-key "$VECTCUT_API_KEY" query-script --draft-id "draft_xxx"
```

常用命令包括：

- `upload-video`：把一个或多个本地视频上传成临时视频链接。
- `duration`：查询视频或 BGM 时长。
- `asr submit-and-wait`：提交并等待字幕识别。
- `execute-workflow`：一次性创建草稿并写入主视频、标题、双语字幕、关键词弹出、音频、提示音、转场和关键帧。
- `create-draft`、`add-video`、`add-text`、`add-audio`、`add-preset`、`add-keyframe`：只在调试单个动作或工作流失败定位时使用。
- `query-script`：查询草稿结构。
- `render submit-and-wait`：用户要求预览时渲染视频。

## 异常处理

- 单个视频的 ASR、语义规划或工作流写入失败时，记录该视频失败原因；如果还有其他视频，继续处理后续视频。
- ASR 没有有效句子时，不继续生成效果。
- 规划结果不合法时，只重试一次；不要用猜测数据继续写草稿。
- 查询草稿没有通过校验时，不要报告“完成”。

## 最终回复格式

成功时最终回复必须和鱼眼 INS 模板保持同一种展示效果，不要输出大段 JSON，不要自由发挥成过程日志：

1. 第一行说明已完成高级红口播草稿；如果没有渲染预览，写明“未渲染预览视频（按模板规则，只有明确要求预览时才渲染）”。
2. 单个视频使用“新草稿：”小节；多个视频使用“草稿列表：”并按视频顺序编号。
3. 每个草稿用短项目展示 `draft_id`、草稿链接、关键模板参数和校验结果。
4. 最后可补一句字幕拆分摘要，但不要输出完整字幕明细，除非用户要求。

单个视频回复示例：

```text
已完成高级红口播草稿，未渲染预览视频（按模板规则，只有明确要求预览时才渲染）。

新草稿：
- draft_id：dfd_xxx
- 打开草稿：https://www.vectcut.com/draft/downloader?draft_id=dfd_xxx&is_capcut=0
- 标题样式：高级红双行标题
- 字幕样式：思源粗宋 + Poppins_Bold 双语字幕
- 校验结果：video_main 9 段、文字层 32 个、转场 3 个、关键词弹出 4 个、缩放关键帧 1 组、提示音 2 个、BGM 1 段

这版字幕拆分为：9 条短字幕。
```

不要在最终回复里输出临时脚本名、代码 diff、已编辑文件、调试文件、接口请求体或完整接口响应。

## 交付标准

只有草稿创建成功、主视频时间轴连续、标题、双语字幕、关键词弹出、转场、缩放、提示音和 BGM 都通过校验后，该视频才算成功。最终回复必须遵守“最终回复格式”，不展示接口请求细节。
