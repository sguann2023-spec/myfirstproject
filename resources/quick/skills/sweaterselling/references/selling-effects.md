# 视觉增强规则

本模板支持两种图片视觉增强，但同一图片素材只能触发其中一种，且两种效果不能在同一时间段同时展示：图片和口播片段替换预设，或图片画中画。

固定预设：

- `preset_id=12a0de93-6440-4b42-923e-54345def9193`
- `image1=匹配图片 URL`
- `video1=口播视频 URL`
- `video1` 不直接使用原口播长视频 URL；必须先调用 split-video 异步接口，按命中 ASR 句子的源视频开始时间截取短视频，拿到新 URL 后再放入 `replacements.video1`。
- `add_preset` payload 中 `start/end` 传截取后短视频的相对窗口，必须为 `0 -> 预计截取的原视频时长`，时长不低于 3.5 秒，不传口播源视频绝对时间。
- `volume=-60`，避免预设替换视频带出重复人声音轨。

图片画中画：

- 使用 `add_image` 写入 `track_name=happy_image_pip`。
- 展示时长固定 2 秒，不能超过 2 秒。
- 只有模型选择的起点后至少还剩 2 秒时才写入；片尾不足 2 秒时跳过。
- 位置：`transform_x_px=0`、`transform_y_px=0`。
- 缩放：根据 1080x1920 画布和图片实际尺寸计算，公式为 `min(1080*0.46/image_width, 1920*0.42/image_height, 1.0)`；探测不到尺寸时兜底 `scale_x=scale_y=0.42`。
- 入场动画：`便利贴`，`intro_duration=0.35`。
- 出场动画：`向上滑动`，`outro_duration=0.35`。
- 预设占用过的同一 `image_index` 或图片 URL 不得再用于画中画。
- 画中画展示区间不得与任一预设展示区间重叠；若重叠，跳过画中画，不自动改动模型选择的时机。

字幕增强只通过 `add_text.text_styles` 完成：

- 字体：`快乐体`
- 普通文字颜色随机：`#ff96c2` 或 `#FFFFFF`
- 关键词颜色：`#ffdd22`
- 所有文字描边：`#000000`
- 描边宽度：`30`
- 字幕 y 轴：`transform_y_px=-800`

不要主动添加贴纸、花字、文字模板或场景特效。
