# 执行流程

1. 确认口播视频、本次 VectCut API Key 和可选素材 URL。
2. 查询口播视频时长，提取口播音频，默认用 `llm_vad` 做 ASR。
3. 基于 ASR 生成统一去气口时间线，主视频、口播音频和字幕都复用这份时间线。
4. 根据口播文案生成草稿标题基础词，创建草稿时追加本地时间戳。
5. 将素材按图片和视频分类；图片先由当前 Codex/本地视觉模型理解，本地分析失败时自动调用 VectCut LLM Chat 的 `image_url` 接口；视频先调用 VectCut 视频分析接口。
6. 根据口播文案、ASR 时间线和素材分析，选择适合添加图片预设、视频画中画或图片画中画的句子。
   - 开场推荐或整体商品展示：商品整体图使用图片画中画。
   - 摸起来、看起来、材质、面料、纹理、柔软、亲肤、做工等细节描述：细节图使用图片+口播片段预设。
7. 执行互斥校验：图片预设、视频画中画、图片画中画三类效果同一时间段只允许一个，重叠候选跳过。
8. 视频画中画区间内，素材视频作为背景展示，口播主视频切换成右侧中间画中画。
9. 写入口播主视频、素材预设或画中画、快乐体字幕、口播音频和 BGM。
10. 查询最终草稿结构，输出草稿链接、运行目录、任务 ID 和效果写入统计。

失败处理：

- 没有素材：只生成全程口播视频、字幕、音频和 BGM。
- 素材类型无法识别：跳过该素材，继续处理其他有效素材。
- 图片理解先按“Codex/本地视觉模型 -> VectCut LLM `image_url` -> 元信息记录”顺序处理。只有两种视觉分析都失败时才进入元信息记录；此时不得根据随机文件名推断图片内容，并在结果中记录失败原因。
- 视频分析或效果规划失败：跳过素材效果，仍生成基础口播字幕草稿。
- 口播可截取片段不足预设最低时长：跳过对应预设候选。
- 素材视频可截取片段不足 2 秒：跳过对应视频画中画候选。
- 画中画起点距离片尾不足 2 秒：跳过该画中画，不强行挪动模型选择的时机。
- 三类素材效果时间段重叠：保留先通过校验的效果，跳过后续重叠候选。
- `add_preset` 或 `add_image` 失败：记录请求和响应，最终说明成功/失败数量。
