# 目标与边界
这是固定风格、替换内容的 hybrid 技能，不是参考片分析技能。绝不要求用户提供或读取参考视频，也不依赖旧草稿、旧素材工作区、历史签名URL。风格数值见 references/style.md，输入契约见 example.json。技能分发包不携带任何图片、视频、音频或字体资产。
默认交付可编辑剪映草稿，而非合并视频。云渲染仅用于验收。仅用当前可用工具；通过 searchTools 发现并 describeTool 检查当前参数，不能照抄历史调用。不要重新生成用户已经做好的口播。

## 输入
必要：新的口播视频（本地文件或可访问URL）。可选：准确文案、标题、产品图/视频、品牌透明PNG、AI开头素材/提示词、配乐、目标时长、片尾文案。
默认：1080×1920、30fps、严格不超过60秒（计划上限59.5秒），无默认品牌，模型 minimax-h3，开头5.4秒、产品0.5秒、尾卡2.8秒。
只有文案时不要假称能剪辑，询问口播文件；如用户明确要生成数字人，再补齐人物/音色并调用相应工具。素材齐全即开始，不反复确认风格。
换品牌时不能复用旧logo/产品/尾卡；缺少新品牌素材时询问或省略品牌层并报告，风格仍保留。新主题不匹配宝宝哭声/大脑贴纸时必须替换或省略，不机械照搬。

产品闪切需要 `videos.product_footage` 或 `images.product` 至少一种；品牌包装需 `images.brand_assets`。缺少时询问补齐或明确说明省略，不能自动取历史素材。`example.json` 中 `upload://` 仅为占位符，执行前必须替换为实际上传地址。
配乐、音效、科普贴纸可由用户在制作要求中附上有效素材地址，或通过当前可用工具获取/生成（遵循授权）。BGM、结尾ding等可选音频缺少来源时询问或省略并说明；但AI开头的自然情景声为默认必需，不能随可选配乐一起省略。无可用声音来源时暂停开头验收并询问用户，不声称有默认文件。所有媒体保存在本次工作区，不加入技能包。

## 运行文件
每次在当前工作区创建独立 runs/<时间-主题>/。保存 input.json、probe.json、transcript.json、plan.json、state.json、qa/、delivery.json。state记录素材路径、生成任务ID、草稿ID、逐步添加的素材ID、渲染ID/状态；每步成功即落盘。不得覆盖旧草稿。
脚本 scripts/timeline.py 根据已经确定的语句切点生成连续时间轴和时长方案；MCP调用由助手通过运行时执行。脚本不连接私有API、不模拟工具成功。references/style.md 是调用和验收规则。

## 执行顺序
1. **检查**：检查路径/URL、ffprobe媒体流、旋转、分辨率、音视频时长、音量。上传必要素材获得新URL，禁止复用过期URL。只使用本次上传素材或本次获取/生成的素材，并保存到本次运行目录；禁止读取作者旧工作区或回写技能目录，草稿素材不得依赖临时缓存。
2. **语音是时间轴**：对口播做带时间戳ASR。用户文案用于校对，不能把文字均分估算字幕时间。沿句间停顿挑约5–12秒的段，通常5–8段；不得切断字音。保留完整原意和健康风险提醒。把实际语句末尾作为 scripts/timeline.py 的 cuts（从0开始、以实际口播总时长结束）。超时先移除无意义静默，必要时按脚本建议≤1.12倍统一变速；仍超时请求用户授权删减，不擅删句子或强行交付超长片。
3. **开头**：优先使用用户提供的情景素材，否则发现视频生成工具，检查支持的模型，以 minimax-h3 生成9:16写实情景。主题来自新文案的钩子，不固定复述旧话题。宝宝睡眠题可用：暖色夜灯下婴儿床中宝宝熟睡，镜头缓慢推进，轻轻皱眉、手指活动、嘴角下撇，生活实拍质感，无文字无logo，无夸张惊吓、无危险睡姿或松散被褥遮脸。取5.4秒，不足时调整计划。**开头默认必须有自然情景声音，不是无声画面，也不是另加解说。** 生成提示词同时写明声音设计：安静卧室底噪、轻柔呼吸，与宝宝轻皱眉/活动手指对应的短促轻哼唧；画面出现嘴角下撇或哭闹时才匹配轻微呜咽，不用夸张尖叫、持续大哭或惊吓音。按当前schema请求音频生成（如支持则显式 generate_audio=true），不请求silent或禁用音频。capabilities中generate_audio_supported的含义必须按当前工具说明解读，不能把“不支持关闭音频”误读成“不支持声音”。提交后记录任务ID并等待/查询同一任务；禁止超时就重复付费提交。生成失败可用已有素材，或询问，不擅换付费模型。下载后检查音轨并试听/音频理解，确认不是静音且声音与画面匹配；仅存在audio stream不算通过。如果本次输出无声或声音不合适，优先用本次合法提供/经许可获取或生成的情景音效独立轨补齐，不重新生成口播、不擅换付费视频模型、不为补声音盲目重提视频任务。若获取/生成声音需要额外授权则先询问；无法补齐时报告阻塞，未经用户明确同意不能交付为“开头声音验收通过”。
4. **素材预处理**：产品图做0.5秒特写或使用产品视频；不要从参考片截取。人声测量后按需规范到约−16 LUFS、true peak≤−1.5dB，不盲目加20dB。保留原始文件。音频比画面稍长≤0.2秒时可补最后一帧，明显差异要排查同步。轻钢琴循环需交叉淡化，随总时长动态生成，不能把58秒BGM直接强行截用于所有片子。
5. **基础剪辑建草稿**：create_draft；主轨依次 add_video 或 add_image：AI开头→产品→口播分段→尾卡。不要用模板/预设生成整片。各口播段依次缩放1.00/1.10/1.00/1.10/1.00/1.12，循环使用。裁切保留脸和手势。音频使用原口播或其规范化版本，禁止叠放两份人声。AI开头优先保留已验证的原生情景声，不能默认静音；使用独立情景声替代时才关闭原生音轨，避免双份叠加。音量参数先确认当前单位（dB或线性倍数）；不能假设volume=0一定静音，查询真实草稿增益并渲染验证。统一变速时，视频/人声/字幕使用同一源到目标映射。逐步记录素材ID并查询实际草稿验证。
6. **品牌和信息层**：品牌盾标左上、招牌右上，避免挡脸；已内嵌logo的素材不再叠加。按本次输入的实际透明边界与画布尺寸布局，不假定上传图是全画布贴片。按新文案语义放1个适当科普贴纸，大脑仅用于大脑/神经话题，不要固定旧时间17.69秒。尾卡优先使用黑底+可编辑文字重建“下期再见 / 记得点赞关注加粉丝群哦”，品牌logo独立层；不携带旧尾卡图，不从旧项目截取。
7. **字幕**：来自真实语音时间戳，7–13汉字/行，适当按意群拆分。白字黑描边+少量黄色关键词，单条富文本实现，不做双层hack。正文字幕中心约y=1420。AI开头可放两条无旁白钩子字，不伪装成ASR。具体参数及失败处理读 references/style.md。
8. **音频**：AI开头必须有清楚可闻、自然且匹配动作的情景声，不以BGM代替情景声。优先保留生成视频内合格的原生声音；补充/替代情景音效时单独成轨，记录来源及与画面动作对应的实际时间。开头情景声在口播开始前收尾或短淡出，不压住第一句；不得为制造噩梦感加入恐怖声。bgm、独立情景音效、结尾ding单独轨道。BGM比人声低约15–20dB；开头淡入1.5秒，片尾淡出2.5秒。情景音效仅匹配主题时用，不能压住口播；ding在尾卡开始。每轨不可重叠，否则可能被渲染器静默丢弃。
9. **云渲染验收**：先抽检开头、第一段人声、关键词/最长字幕、贴纸段、尾卡各3–5秒，可创建QA短草稿或使用工具支持的范围渲染。每段应包含相同图层/音量。检查取景、字幕单行/描边/高亮、logo重叠、音量、ding。开头额外检查：真实渲染中有自然情景声、无意外静音、无重复声轨、声画匹配、接入口播时无突兀响度跳变。必须试听或用可用音频理解工具检查，并结合响度/峰值测量；渲染任务SUCCESS不等于声音验收通过。问题先诊断参数再局部修改，查询更新后的真实状态，再渲染关键段。QA不等于成片交付，不默认渲染最终整片。云渲染不可用时明确验收未完成，不能声称通过。
10. **结构验收与导出**：查询草稿并运行 scripts/timeline.py check 对真实JSON检查主轨连续、正时长和≤60秒；同时人工检查字幕映射、无丢素材、源片段没有越界、无双人声。失败不能交付为成功。最后 export_draft 导出剪映工程。检查返回的实际状态；只 accepted 时说“已提交导出”，不要说客户端已打开。保存delivery.json：draft_id/name、实际时长、规格、运行目录、验收结果、未解决事项。用户未授权不清除QA草稿，不发布。

## 汇报与恢复
阶段汇报用“素材已检查 / 时间轴已确定 / 草稿搭建完成 / 云渲染验收 / 导出状态”，给真实ID和结果，不虚构工具调用数量。失败保存state并从最后成功步骤继续；添加失败先查询实际素材/segment ID，不盲删盲加；付费任务先查状态，避免重复提交。
交付简洁：草稿名与ID、时长、结构、导出状态、影响使用的限制。此技能不保证模型输出逐帧一致，但剪辑布局、节奏、字幕和音频层次应一致。
