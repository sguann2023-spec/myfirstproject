# 固定风格与已验证经验

## 视觉参数
- 画布1080×1920、30fps。风格结构：5.4s暖夜情景钩子 / 0.5s产品闪切 / 口播交替近景 / 2.8s黑底尾卡。时长可根据口播预算缩短开头，不通过掐断正文凑时长。
- 默认时长公式：5.4+0.5+实际口播时长/速度+2.8。计划≤59.5秒，硬上限60秒。
- 字体：尔雅新大黑，历史字体ID 7217732136894206501 仅作检索线索，不保证当前可用。找不到用可用粗黑体并报告。云端不接受本地字体路径时，QA使用可用粗黑体，交付字体另行确认；不能说字形完全一致。
- font_size=11、居中、白色#FFFFFF、描边黑色#000000、宽度0.12；高亮#FDF48A。字号/描边是工具单位，不是像素。画面验收优先于死记参数。
- 字幕中心目标(x=540,y≈1420)，单行7–13字，约82%画幅以内。历史 transform_y_px=-920 对应真实y≈1419，-460会落到1190；不同工具版本必须短片实测，不照搬坐标假设。
- scale_x/scale_y是倍数1.0/1.1/1.12，绝不是100/110。
- 不要用大面积整句黄字，每条1–2处关键词，高亮覆盖约20–40%文字即可。

## 富文本
先检查add_text当前schema。曾验证的局部样式形态：
```
{"start":0,"end":2,"size":11,"style":{"color":"#FDF48A"},"border":{"width":0.12,"color":"#000000"}}
```
具体颜色类型、索引定义以当前schema为准；所有范围覆盖完整文字，黄/白区间均带描边。历史错误键range/color/border_width被静默忽略并出现红字，不把旧版错误payload再用一遍。references/verified-subtitle-sample.json 是真实剪映素材输出结构样本，不是add_text调用参数，严禁直接当成请求。

## 素材来源与可分发边界
技能只保存规则、脚本和结构示例，不附带媒体资产，也没有默认品牌。产品图/视频、品牌Logo与招牌由用户按 example.json 输入。不得读取作者的工作区、旧项目或历史签名URL。
产品视频与产品图片二选一；需要品牌包装时提交对应品牌图片。缺失则询问或明确省略并重排时长。按实际图片透明边界布局，不预设为全画布贴片。
AI情景、科普贴纸、钢琴BGM、情景音效与尾卡ding使用本次提供或通过可用工具获取/生成的素材，遵守授权并记录来源；可选BGM/ding不可用时说明并询问或省略。AI开头自然情景声为必需，不能默认省略：优先使用视频生成的合格原生音轨；无声或不匹配时以经许可的独立情景声补齐，无来源则询问并标记声音验收阻塞。尾卡用黑底和可编辑文字新建。新主题不匹配大脑贴纸或哭声时不使用。
所有媒体保存至本次工作区的独立运行目录，不回写技能包。示例upload://必须替换为真实上传地址后才可执行。

## 音频与渲染
- AI开头默认有自然情景声、无额外解说。宝宝睡眠题使用轻卧室底噪、柔和呼吸、与动作对应的短促轻哼唧；有哭闹动作才放轻微呜咽，不强配尖叫/惊吓声，不用BGM冒充情景声。
- 视频生成提示词必须描述声音；当前工具支持时显式请求generate_audio=true，不主动生成silent。capabilities的generate_audio_supported按工具说明解释，不能推断false表示不能出声音。
- 下载后检查音轨、响度/峰值并试听或音频理解，只有音轨元数据不能证明可闻且正常。开头合格原生声音不静音；独立音效替代时才关闭原生声音，禁止双份叠加。缺声先补声音，不盲目重新付费生成整段视频。
- volume单位以当前工具和真实草稿为准；本次发现调用数值可被按dB转换为线性增益，volume=0未必静音，不能把6.77当6.77倍。修改后查询实际segment.volume并做短片音频验收。
- 开头情景声在口播开始前自然收尾/短淡出，云渲染后必须检查可闻、声画匹配、无双声/突变。仅render SUCCESS不可标记声音验收通过；未确认时在delivery.json记录未完成项。
口播规范目标约−16 LUFS / TP≤−1.5dB。BGM低于口播15–20dB，以实测为准，不机械套volume=1。历史最终混音mean约−19dB、max约−4.1dB仅用于参考，不是LUFS。
每条音频轨只放不重叠片段；bgm、baby、ding分轨。末尾静音检查ding真实存在。视频也带音轨时不得重复add_audio同份人声。

## 故障诊断
- 放大糊成色块：检查缩放是否误用100。
- 黑屏：检查主轨是否出现duration=0、是否存在空洞、URL失效；成功响应不代表实际片段正确。
- 删除失败：从实际草稿查material_id/segment_id，按当前schema需要传正确ID，不把缓存文件名当素材ID。
- 添加报重叠：先查询原段是否仍在，勿不断重试相同添加。
- 黄字红/无描边：检查当前富文本schema、短样片验证，不用双层字幕掩盖参数错误。
- 字体云端报错：改云端可用字体试样片，禁止悄悄改变最终风格不报告。
- 口播末尾画面比声音短：≤0.2秒补帧可接受，明显差异需同步处理。
