# 执行流程

## 1. 准备时间线

1. 获取口播源视频时长。
2. 提交 ASR/去气口任务。去气口只压缩 ASR 识别到的前中段气口，不得删除原视频最后的静音尾段。
3. 得到统一时间线：
   - `timeline_segments`: 字幕句子，包含 `source_index`、`text`、`start`、`end`。
   - `video_clips`: 源视频片段到目标时间线的映射。
   - `timeline_duration`: 去气口后的草稿总时长加原视频尾部保留时长。
   - `preserved_trailing_silence_ms`: 接回统一时间线的原视频尾部静音时长。
4. 如果去气口开启，后续视频、字幕、BGM、素材、特效全部使用该目标时间线。

## 2. 标题和草稿

1. 如果用户没有传标题，用 LLM 生成两行标题。
2. 创建 1080x1920 草稿。
3. 草稿名使用标题加时间戳。

## 3. 主视频和字幕

1. 用 `video_clips` 循环添加口播视频分段。
2. 不允许直接把原始口播视频整段铺满。
3. 用 `timeline_segments` 逐条添加字幕。
4. 字幕轨道时间必须和口播视频目标时间线一致。

## 4. 素材分析

1. 识别每个素材的 `image|video` 类型，保持用户传入顺序和素材 index。
2. 对所有图片素材逐条进行图片理解：优先使用当前 Codex/本地视觉模型；本地分析不可用、失败或返回空结果时，脚本自动调用 VectCut LLM 的 `image_url` 接口兜底。文件名、URL、尺寸和扩展名只用于标识或技术探测，不能作为图片内容判断依据。
3. 对所有视频素材逐条获取时长，再逐条走视频分析接口，例如 `video_detail`。
4. 输出完整素材摘要供 LLM 匹配文案，不得因为第一条素材已经匹配成功就停止分析后续素材。视频的 `video_detail` 分析文本必须参与语义匹配，不能只用于确定素材截取区间。

所有画中画候选窗口都必须满足：

- `start >= 2000ms`。
- `end <= timeline_duration - 2000ms`。
- 如果素材最长展示 3 秒，实际窗口必须同时满足 `start + duration <= timeline_duration - 2000ms`。
- 模型返回越界窗口时，先尝试在同一匹配句内调整；无法调整则放弃该效果，不能写入越界窗口。

## 5. 背景画中画

1. 让 LLM 从全部素材中选择最强匹配素材和句子开始时间，输出一个背景画中画候选；背景画中画每个草稿最多一次，背景素材可以是图片或视频。
2. 窗口最长 3 秒；图片和视频素材都不能超过 3 秒。
3. 窗口必须完全避开开头 2 秒和结尾 2 秒保护区。
3. 素材全屏做背景，`relative_index=1`。
4. 口播视频在该窗口内切成右侧 PIP，窗口外仍全屏。
5. 把窗口加入 `occupied_windows`。

## 6. 视频素材 PIP + 模糊

1. 只允许从全部视频素材中选择一个最强匹配候选；视频素材 PIP+模糊每个草稿最多一次，且不能使用已经作为背景画中画的素材。优先比较商品、主体、动作和卖点语义；“便利店、超市、货架”等通用场景词不能单独构成匹配。分析成功但没有语义匹配时跳过该素材，不得按素材顺序把它分配给前几句文案。
2. 时长 2 到 3 秒，最长不能超过 3 秒。
3. 每个窗口不得与 `occupied_windows` 或其他已接受的视频素材窗口重叠，也不得进入开头 2 秒或结尾 2 秒保护区。
4. 主口播视频保持全屏。
5. 同时间段添加模糊特效。
6. 添加素材视频 PIP，位于画布中间。

## 7. BGM 和关键词

1. 添加 BGM 覆盖 `timeline_duration`。
2. 让 LLM 选择少量促销/自评关键词。
3. 按关键词类别调用文字模板。
4. 同一模板每分钟最多 2 个。

## 8. 最终校验

- 标题结束时间是 3 秒。
- 原视频尾部静音被保留在时间线末尾，草稿总时长包含该尾段。
- 字幕、口播视频、BGM、素材和特效使用同一目标时间线。
- 所有画中画窗口均满足 `start >= 2s` 且 `end <= 总时长-2s`。
- 背景画中画和视频素材 PIP 不重叠。
- 背景画中画最多 1 个，视频素材 PIP+模糊最多 1 个；每个被跳过的素材都有明确原因。
- 模糊特效时间与素材视频 PIP 完全一致。
- 层级为主视频 < 模糊特效 < 素材视频 PIP。
- 关键词模板轨道统一，数量满足每分钟上限。
