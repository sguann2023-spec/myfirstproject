# 输入和输出

## 必填输入

- `jwt_token`: 用户本次提供的 VectCut JWT/API token。
- `video_url`: 口播视频公网 URL。

缺少任一必填输入时先询问，不创建草稿。

## 可选输入

- `title`: 用户指定标题；如果为空，由 LLM 根据口播文案生成两行标题。
- `text_content`: 用户提供的完整文案；可用于 ASR/去气口辅助对齐。
- `material_urls`: 图片或视频素材 URL 列表；传入多少条就逐条分析多少条，不能只取第一条。
- `cover_url`: 草稿封面，可为空。
- `remove_silence`: 是否去气口，默认 `true`。
- 去气口开启时默认保留原视频尾部静音；尾部静音作为无字幕尾段接回草稿时间线。
- `message_id`: 调试日志名；没有时用时间戳生成。

## 素材限制

- 图片支持常见扩展：`.jpg`、`.jpeg`、`.png`、`.webp`、`.gif`、`.bmp`、`.heic`。
- 视频支持常见扩展：`.mp4`、`.mov`、`.m4v`、`.webm`、`.avi`、`.mkv`。
- 无法从扩展判断时，用 HEAD 的 `Content-Type` 判断。
- 不支持的素材类型直接报错，提示用户替换素材。

## 素材使用规则

- 每条素材都必须完成类型识别、时长探测（视频）和内容分析，再参与文案匹配。
- 图片分析顺序固定为：当前 Codex/本地视觉模型 -> VectCut LLM `image_url` 兜底；两者都失败时标记为不可用，禁止按文件名猜图或参与语义匹配。
- 先分析全部素材，再选择效果；每个草稿最多 1 个背景画中画和 1 个视频素材 PIP+模糊效果。
- 同一素材只使用一种效果；超出效果数量上限、与已占用窗口重叠、不匹配、时长不足或进入首尾保护区时跳过，并记录原因。

## 输出

最终回复包含：

- `draft_id`
- 草稿链接或可打开的草稿信息
- 是否去气口
- `timeline_duration`
- 字幕数量
- 素材数量
- 背景画中画是否触发
- 视频素材 PIP + 模糊是否触发
- 关键词文字模板数量
- 调试日志路径
