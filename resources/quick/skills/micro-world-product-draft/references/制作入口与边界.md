# 固定风格制作入口与边界

## 不是新参考片分析器

下一次只接收本次商品素材和要求。直接使用 SKILL.md 固定骨架，不下载、不拆解新参考片。原有通用技能保持不变。

## 工具包入口

在工作区执行（项目目录必须不存在）：

```bash
python3 skills/micro-world-product-draft/scripts/init_project.py 新商品项目 --product '真实商品名称'
```

初始化只提供目录、脱敏配置和制作脚本，不会自动生成素材或假装已完成草稿。

1. 阅读本次商品素材，核实卖点并填素材盘点和缺口表。
2. 写本次故事与旁白，生成最终VO，再识别最终音频。若预处理了配音，必须识别处理后的音频。
3. 按真实语音时间重排各镜头时长，更新配置。模板中的时间只是预算。
4. 通过运行时发现、检查图像和视频生成工具；优先 MiniMax H3。SKILL.md 中模型参数是意图示例，不是保证有效的API，必须以当前工具 schema 和模型列表为准。模型不存在则说明并选择可用方案，不能虚报模型。
5. 下载/保存新生成媒体到本次项目，商品包装优先用真实素材；更新素材路径。
6. 把 BGM 保存为 assets/audio/bgm_raw.wav（当前预处理脚本约定），或先调整脚本读取配置路径。
7. 执行项目内 prep_clips.py，再编译 build_draft.py。配音输入建议最终 WAV；prep_vo.py 为可选 MP3 预处理工具，依赖 numpy，不可无条件改变用户源口播。
8. 创建新草稿并填入新ID。draft_ops.json 只是操作清单，不是剪映草稿。执行前逐一检查当前 MCP 参数/字体/动画能力，必要时调整编译器；使用运行时协议调用，不在普通终端里假装执行 tools。
9. 查询实际草稿；verify_draft.py 默认读取项目父目录下的 <draft_id>.json。若 query_script 落盘位置不同，应明确提供快照或复制到该处再校验。
10. 检查媒体路径、音画连续性和原生层；检查开场、三连卖点及CTA。只有结构校验的结果应明确写“结构校验通过、客户端视觉待验”，不可声称已视觉复检。
11. 按用户授权导出入队。入队成功不等于桌面端已导入成功。

## 脚本适用边界

- templates/edit_plan.template.json 从历史版式抽取并清除了旧商品名、功效、素材路径、台词与草稿ID。保留字号/色彩/轨道和镜头功能。
- scripts/ 为项目版编译器起点，不是无须调整的通用自动剪辑服务；脚本不会理解素材、生成视频或自动做ASR。
- 编译器按镜头顺序累加时长，以镜头级字幕为主。逐字/逐句独立字幕需根据本次ASR扩展文本操作，不能声称默认已实现逐字对齐。
- 编译器只覆盖母版常用轨道；需现场原声时应新增轨道和独立音频操作，不能只写在文档里而不实际装配。
- 字号约5.7像素/单位、Y偏移约二分之一等为历史后端实测，不是所有版本通用事实。换环境先用小样预览标定。
- 原生文字/关键帧可编辑不等于AI视频内部可编辑。角色、泡沫和场景动画属于AI素材本身，修改它们通常需要重新生成镜头。
- 不自动安装全局技能，不改其他技能，不删除测试项目。用户明确要求安装到全局后才进行该操作。
