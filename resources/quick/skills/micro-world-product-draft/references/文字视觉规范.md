# 微缩世界同款：文字视觉制作规范

## 目标与历史问题

沿用已交付母版的粗标题、黄白层级、深色描边、投影、弹入、卖点色块及分层CTA，不把可编辑草稿做成普通白字字幕。
历史配置已有优设标题黑、抖音美好体、得意黑及4/6/8px描边，但脚本只为主字幕显式开启阴影，关键词、大卖点和CTA未统一开启；此前也没有原生文字模板编译入口。执行时若绕开配置或字体解析失败，更容易退化成系统字体。必须同时落实配置、资源选择、实际写入和视觉检查，不能仅修改文案规范。

## 字体职责与样式配方

以下像素值是1080×1920画布的目标视觉，不是直接传给API的字号。编译器的历史换算应先预览标定。

| 层级 | 首选字体（需核实可用性） | 目标字高 | 字色/描边 | 阴影/进场 |
|---|---|---|---|---|
| 主字幕 | 优设标题黑 | 60px | 白/深绿黑4px | 黑色60%投影、弹入0.25s |
| 痛点与关键词 | 抖音美好体 | 84px | 黄/深绿黑6px | 黑色65%投影、二段缩放0.32s |
| 三连卖点 | 抖音美好体 | 96px | 黄或品牌强调色/深色8px | 黑色65%投影、三次节奏一致 |
| 卖点副标 | 优设标题黑 | 42px | 浅色/深色2px | 轻投影、深色圆角底、渐显 |
| CTA大标题 | 抖音美好体或得意黑 | 74–134px | 黄白/深色3–6px | 投影、错峰进场 |
| CTA动作 | 得意黑 | 50px | 白/深色2px | 投影、按钮底板、弹入 |
| 免责声明 | 可读的思源等正文体 | 22–26px | 白/深色细描边 | 不加夸张动画，以可读为先 |

全片建议2–3个主字体家族，不是每句话换字体。思源/系统字体仅适合小字或明确的品牌要求，不得默认用于整条视频的花字。首选字体不可用时先浏览当前真实字体字形，再挑同气质粗标题字体；记录替代关系，不冒称使用了不存在的字体。

阴影建议起点：shadow_enabled=true，shadow_color=#000000，shadow_alpha=0.65，shadow_angle=45，shadow_distance=6，shadow_smoothing=0.15。这些是待预览的样式起点，不保证不同后端视觉一致。描边和投影必须实际写入操作参数；不能把阴影当成描边的替代。高亮背景上要保持边缘可辨，暗背景上不应黑成一团。

## 真正的剪映文字模板（不是JSON样式配方）

每次制作发现 get_text_template_previews，先检查schema、浏览实际预览，再用 add_text_template 装配。禁止编造模板名或ID。选取至少2处视觉强调位置：钩子、英雄登场、卖点组或CTA；同一卖点组尽量同系列。避免套婚礼、横屏长标题等不匹配风格。

核对：方向、texts_count、中文容量、原有装饰是否遮挡商品、模板动画及字体是否可用。模板已经负责某一句时，移除对应普通花字，避免同字叠印；基础字幕仍可保留但不能相互遮挡。模板内部字体/描边/动画可能受模板资源限制，不承诺每个装饰都可单独编辑。

在 edit_plan.json 的 draft.text_templates 中登记：

```json
{
  "enabled": true,
  "role": "hero",
  "template_id": "填写本次实际预览选中的ID",
  "preview_verified": true,
  "texts_count": 1,
  "texts": ["本次英雄口号"],
  "start": 7.0,
  "end": 9.5,
  "track_name": "08文字模板·英雄"
}
```

以上仅为字段示例，ID不可直接执行，时间需按本次最终VO/ASR替换。preview_verified仅在实际看过该模板后填写。编译器检查ID、槽位数及时间范围，但不能验证资源真实可用或替你删掉重复花字。

模板不可用、下载失败或可编辑性不满足时，记录原因，改用原生文字＋描边＋投影＋动画＋可编辑底板，不允许静默退化成裸字。不因套模板而改坏商品信息。

## 必须执行的质检

1. 用 get_font_previews 检查本次中文关键字字形；用 get_text_style_preview 检查主字幕、关键词、卖点、CTA四种样式。工具名称和参数以当前发现为准。
2. 写入项目 analysis/文字视觉选型.md：角色、实际字体、颜色、描边目标和API值、投影、动画、模板ID及选型原因、替代原因。
3. 查看 draft_ops.json：主要原生文字有非零border_width、border_color及shadow_enabled；已选模板有add_text_template操作。主字幕单独有投影不代表全片通过。
4. 查询实际草稿，核对文字材质、字体资源、描边和阴影，核对模板已加入。查不到字段不能判定效果已生效。
5. 开场、英雄、卖点最密集区及CTA做视觉检查；轻量预览不能替代最终合成验证。未做客户端/合成检查应明确“样式参数已写入，最终视觉待验”。
6. 保留VO/ASR对齐、分轨、有效本地绝对路径等原规范。可编辑不是视觉降级的理由。
