# 微缩世界化妆品带货

## 执行入口（先读）

开始制作前先阅读 `references/制作入口与边界.md` 和 `references/文字视觉规范.md`。本技能不需要新参考片；只把本次商品素材代入固定风格。文字视觉规范是必做要求，不是可选建议：保留母版字体层级、描边、阴影和动画，不得退化成全片思源/系统白字字幕。

工具包包括：
- `scripts/init_project.py`：在工作区初始化独立项目，拒绝覆盖已有目录；
- `templates/edit_plan.template.json`：已清除历史商品信息的版式与结构模板；
- `scripts/prep_clips.py`、`prep_vo.py`：可选素材/配音预处理；
- `scripts/build_draft.py`：生成操作清单，由助手检查当前工具 schema 后通过运行时执行；
- `scripts/verify_draft.py`：查询快照的结构校验，不替代视觉复检。

```bash
python3 skills/micro-world-product-draft/scripts/init_project.py 新商品项目 --product '本次真实商品名称'
```

模板不是已完成作品；占位文案、素材路径和预算时长必须替换。生成工具参数以当前发现的 schema 为准，不能盲传历史参数。AI视频内部角色动作仍是视频像素；可原生编辑的是字幕、花字、CTA、草稿运镜和独立音轨等，不承诺将AI内部动画还原成剪映元素。

## 一、技能定位

本技能固化的是已经验证过的**固定创意风格与剪辑语法**，不是“拆解用户新参考视频”的通用技能。

风格母版来自已完成的 30.5 秒项目，其核心为：

```text
微观奇观拦停
→ 痛点变成拟人小怪
→ 常规方法失效，冲突升级
→ 产品/产品能力英雄登场
→ 视觉化爽点解决问题
→ 从 AI 世界切回真实实拍
→ 三连卖点或成分排比
→ 包装/详情/实拍形成信任状
→ 产品定帧与 CTA 收尾
```

下次执行时：

- **不要求用户提供参考视频**；
- **不重新寻找或拆解新参考片**；
- 默认沿用本技能内已经固化的爆款结构、镜头功能、视觉语法、声音语法和剪映轨道设计；
- 每次只根据用户本次提供的新商品、新素材和新要求，生成新的脚本、AI 镜头、配音、时间轴和剪映草稿；
- 不能把上一条欧莱雅项目的商品素材、AI 视频、台词、品牌信息或时间戳直接复用到新项目；
- 可以复用的是**结构和制作方法**，不是上一条片子的具体内容。

本技能的主交付物是**全新的可编辑剪映草稿**，不是先渲染白成品再反拆草稿。

## 二、适用范围

### 最适合

- 洁面、洗护、护肤、身体护理；
- 清洁剂、去污、除味、除螨等具有“问题—清除”关系的产品；
- 可以把痛点视觉化、拟人化，并能表现“英雄解决”的消费品。

### 可以适配

- 防晒、保湿、修护、控油等不以“清除”为核心的商品，但必须改写爽点：
  - 防晒：紫外线怪物被防护盾挡住；
  - 保湿：干燥裂谷被水分能量修复；
  - 修护：受损屏障城墙被修复队重建；
  - 除味：异味烟雾怪被吸附或驱散。

### 不宜强套

若商品无法形成清晰的“痛点反派—产品能力—结果闭环”，不要机械生成小怪大战。应先告诉用户该风格与商品不匹配，并询问是否仍要使用，或转用其他技能。

## 三、输入契约

### 用户输入入口与承接规则

以本技能根目录 `example.json` 展示的输入形态为准：用户提交一段自然语言要求，以及商品图、详情使用图、商品实拍、使用实拍中的一项或多项。用户不需要把请求整理成工程配置。该文件是输入样例，不是本次执行命令；只有用户实际提交的提示词和附件才是本次项目输入。

| 输入字段 | 如何承接 |
|---|---|
| `inputs.prompt` / 用户本次提示词 | 提取商品名称、受众、已确认卖点、时长、视频模型偏好、CTA、价格优惠、可编辑要求和交付方式；本次明确要求优先于示例默认值 |
| `inputs.images.product` | 商品正面图候选，下载看图后确认外观、品牌及可读信息 |
| `inputs.images.details` | 详情或使用图候选；核对内容后提取有出处的信息，不因分组而直接认定为功效证据 |
| `inputs.videos.product_footage` | 商品实拍候选，检查正面、手持、背标及可用区间 |
| `inputs.videos.usage_footage` | 使用与质地实拍候选，检查动作和画面质量，再映射到镜头功能 |
| `parameters.model` / 用户选择的执行模型 | 对话执行模型，不等同于 AI 视频生成模型；提示词中的 MiniMax H3 才是视频模型偏好 |

承接时必须遵循：

1. 图片与视频是替代或互补关系，不要求四组齐全；至少一项附件能确认真实商品外观即可开始盘点。分组、文件名、描述只是线索，以实际内容为准；发现错分可在素材清单中重新归类，无需用户重传。
2. 从提示词和清晰包装、详情中核对商品名称与可确认卖点，不强制用户重复填写可从素材可靠读到的信息。商品身份有冲突或无法辨认时再询问；未提供的价格、优惠、认证及功效不编造。
3. 区分中文方括号中的具体内容与占位符：`【欧莱雅男士氨基酸净澈洁面乳】` 是具体商品名，`【填写真实商品名】`、`【价格和优惠信息】` 是待填内容。括号本身不应进入配音或字幕；未填写的促销占位符直接省略，关键商品身份无法确认才追问。
4. 示例附件 URL 先下载至本次独立项目并核查实际内容。下载失败不冒称已看过；无有效替代素材时请用户重新提供。最终同机草稿使用存在的本地绝对路径。
5. 示例的欧莱雅名称、受众、附件及链接不是固定内容，也不能自动作为下一项目输入。`display_info` 中的点赞、粉丝、链接和 `estimated_usage` 是展示元数据，不是商品卖点、可验证效果、制作预算或用户执行要求；不把展示链接当成需要重新拆解的参考片。
6. 未另行指定时，约30秒、固定微缩世界英雄叙事、视频优先 MiniMax H3、CTA“查看商品详情”、保存剪辑逻辑与配置、交付新剪映草稿而非成片。明确指定其他CTA或交付方式时按本次要求处理；模型可用性仍需现场核查。
7. 先生成本次输入摘要、素材盘点和信息出处，再进入脚本—最终VO—ASR—AI缺口生成—草稿装配流程。用户要求直接制作且无关键歧义时，摘要写入项目文件，不逐项等待确认。`execution_modes`、`validation_rules` 是制作说明，不假定前端解析器已替助手执行验证。

### 最低制作条件

```yaml
product_assets:
  - 至少一项能确认商品真实外观的素材：商品实拍视频或清晰商品图
product_info:
  - 可从本次提示词或素材可靠确认的商品名称
  - 可从本次提示词或素材可靠确认的卖点、成分或功能；不足时用保守文案，不凑造三项功效
request:
  - 用户已提交使用本技能制作新剪映草稿的意图，无需重复填写固定风格和工程参数
```

### 建议提供

```yaml
optional:
  - 商品使用过程实拍
  - 质地、起泡、涂抹、清洁或效果过程实拍
  - 包装正面、背标、成分表、详情页
  - 品牌 Logo 或视觉规范
  - 目标人群与主要痛点
  - 合法有效的价格、优惠和 CTA
  - 禁用词、平台规范、必须保留的免责声明
  - 目标时长（默认约 30 秒）
```

### 不需要提供

- 新的参考视频；
- 参考视频链接；
- 固定时间轴；
- 分镜切点；
- 字体、动画和轨道参数；
- 上一条项目的配置文件。

如果用户又提供参考视频，除非用户明确要求切换风格，否则只把它当补充素材或忽略其风格，不进入“重新拆解参考视频”流程。

### 缺失信息处理

- 没有可靠商品图或实拍：必须索取，不能让 AI 凭空伪造商品包装。
- 成分、价格、优惠、认证或功效不明确：不能编造；可以采用不含这些信息的保守文案。
- 只有商品图、没有过程实拍：允许使用商品图运镜，并由 AI 补概念镜头，但必须说明真实证据镜头较弱。
- 用户说“直接做好”：除关键商品信息缺失或存在高成本歧义外，不逐步等待确认，直接完成草稿。

## 四、固定风格 DNA

以下是技能的固定部分，换商品时不能随意丢失。

### 1. 叙事结构固定

| 段落 | 功能 | 固定表达逻辑 |
|---|---|---|
| S01 | 奇观钩子 | 进入皮肤、纤维、污渍、气味等肉眼不可见的微观世界 |
| S02 | 反派与失败 | 把痛点拟人成小怪；普通方法无效，甚至被小怪嘲笑 |
| S03 | 英雄登场 | 产品或产品能力以英雄/装备/能量形式进入 |
| S04 | 爽点闭环 | 泡沫、能量、护盾、水流或修复队完成可视化解决 |
| S05 | 现实落地 | AI 世界切回用户真实使用或质地实拍，留短呼吸位 |
| S06 | 商品识别 | 正面包装、手持产品或稳定商品特写，完整说出商品名 |
| S07A/B/C | 三连信息 | 三个真实成分/卖点/能力点，以大字排比快速砸入 |
| S08 | 信任状 | 背标、详情页、包装信息、真实过程或适用信息 |
| S09 | CTA | 无字商品底图＋剪映原生可编辑文案收尾 |

### 2. 视觉语法固定

- 前段为高饱和、强质感的 AI 微观世界；
- 痛点必须具有统一、易识别、略滑稽而非恐怖的拟人角色；
- 产品能力登场必须形成明确的“英雄时刻”；
- 解决镜头要有可感知的动态爽点，不能只做产品静态展示；
- AI 段和真实段在色彩、质感上有区分；
- 商品真实包装优先来自用户实拍或商品图；
- AI 不得生成并冒充真实包装小字、Logo、检测报告或使用结果；
- 详情图采用完整展示或模糊底竖版卡，不直接粗暴 cover 裁掉商品信息。

### 3. 节奏语法固定

默认总时长 **28–32 秒**，目标约 30 秒：

```text
0.0–3.5s    S01 微观奇观钩子
3.5–7.0s    S02 痛点反派 / 普通方法失效
7.0–9.5s    S03 产品能力英雄登场
9.5–12.8s   S04 爽点解决
12.8–14.2s  S05 真实质地或使用空拍
14.2–17.5s  S06 商品名与真实产品
17.5–25.0s  S07 三连卖点/成分
25.0–27.8s  S08 信任状
27.8–30.5s  S09 CTA
```

这只是结构比例，不是固定死时间戳。最终切点必须由本次真实配音和 ASR 决定。

### 4. 声音语法固定

- 旁白短句、快节奏、口语化；
- S01 用反问或直接否定拦停；
- S02 用反讽强化“普通方法没用”；
- S03 留一个短促英雄口号；
- S04 用动作词描述解决过程；
- S05 可保留约 0.6–1.2 秒弱旁白或无旁白呼吸位；
- S06 完整念商品名称；
- S07 每个卖点只讲一个核心信息；
- CTA 不编造价格时使用“点头像/看详情/带走这支”等保守引导；
- 水声、泵头、whoosh、冲击、ding 等音效与动作和花字进场对位；
- VO、现场原声、SFX、BGM 必须分轨。

### 5. 剪映版式固定

- 1080×1920，30fps；
- 主字幕白字、深色描边，位于下部安全区；
- 关键词使用黄色或品牌强调色，并独立成轨；
- 三连卖点用大字号花字＋小副标；
- CTA 为无字底图＋多个独立文字层；
- AI 标注和必要免责声明为独立轨道；
- 推近/拉远使用剪映原生关键帧；
- 字幕、花字、CTA、免责声明均不得预烧进视频。

## 五、每次项目必须重新生成的内容

每次换商品，以下内容必须基于本次输入重新完成：

1. 商品素材盘点和可用区间；
2. 痛点反派的具体形象；
3. 微观世界的场景设定；
4. 产品能力的英雄化方式；
5. 旁白和字幕；
6. 三个真实卖点或成分；
7. AI 图片/视频提示词与生成结果；
8. 真实配音、ASR 时间戳和镜头切点；
9. 商品实拍与图片的镜头映射；
10. 结尾卡文案和商品信息；
11. `edit_plan.json`、`剪辑逻辑.md` 和草稿本身。

禁止直接复用上一条项目的：

- 欧莱雅品牌与产品名；
- 油脂小怪、白泵瓶红披风等具体角色设计，除非新商品语义正好适配且已重新生成；
- 旧 AI 视频文件；
- 旧商品图、实拍、配音和时间戳；
- 旧成分与功效文案；
- 旧草稿 ID。

## 六、标准执行流程

### Step 1：建立本次商品素材清单

逐个读取用户提供的图片和视频，检查：

- 文件存在性、时长、尺寸、帧率和编码；
- 商品正面是否可读；
- 使用动作、质地、泡沫或效果过程；
- 包装背标、成分表和详情信息；
- 最佳可用区间与糊帧、遮挡、出画等问题。

按以下等级分类：

- A：商品真实外观与关键信息，必须优先使用；
- B：质量良好的使用、质地或手持实拍；
- C：可作短切、转场或背景；
- D：模糊、重复、错误或破坏节奏，不使用。

产出 `analysis/素材盘点.md` 和 `analysis/素材清单.json`。

### Step 2：套用固定骨架，重写当前商品故事

不分析新参考视频，直接回答以下问题：

- 当前商品解决什么具体问题？
- 问题如何变成一个微观反派？
- 普通方法为什么失败？
- 商品的哪种真实能力适合英雄化？
- 最强的视觉解决动作是什么？
- 哪三项真实卖点适合排比？
- 哪些实拍能把 AI 创意拉回现实？

产出一句话创意、完整旁白和 S01–S09 分镜。

文案必须口语化、短句化，不照搬母版台词。任何成分、功效、价格、优惠、排名和认证都必须来自用户素材或明确输入。

### Step 3：形成素材缺口表

逐镜映射现有素材：

| 分镜 | 固定功能 | 本次内容 | 现有素材 | 缺口 | 解决方式 |
|---|---|---|---|---|---|
| S01 | 微观钩子 | 本次产品痛点世界 | 无/有 | 微观奇观 | AI 视频 |
| S05 | 现实落地 | 质地/使用过程 | 用户实拍 | 无 | 裁切 |
| S08 | 信任状 | 背标/详情 | 商品图 | 动态不足 | 图片运镜 |

默认 AI 负责 S01–S04，真实素材负责 S05–S09。若用户实拍非常强，可以提前进入实拍；若真实素材不足，可用商品图卡补齐，但不能用 AI 假造证据。

### Step 4：生成本次 AI 微观世界镜头

正式生成前先执行下一步的脚本定稿、最终VO与ASR，让镜头长度和动作服务于真实旁白。可在此之前准备美术锚点，但不要按预算时间批量生成最终视频。

优先使用 **MiniMax H3**。以下仅为意图示例；先发现并检查当前工具与模型能力，实际参数必须匹配当前 schema。不可用时说明替代方案，不冒称已用 H3：

```json
{
  "model": "minimax-h3",
  "generation_mode": "first_frame",
  "composeDraft": false
}
```

推荐先生成统一美术锚点，再生成 4 段视频：

1. S01：微观环境＋反派第一次出现；
2. S02：普通方法攻击但失败，反派嘲讽或玩耍；
3. S03：产品能力英雄化登场；
4. S04：明确、连续、可理解的爽点解决。

四镜必须共享：

- 同一世界材质和色温；
- 同一反派造型描述；
- 同一产品能力视觉符号；
- 连续的动作因果关系。

如果 AI 不能正确复现商品包装：

- S03 改为抽象能力英雄、泡沫装置、能量盾或工具；
- 商品本体只在真实 S06 中正式露脸；
- 禁止展示错误 Logo 和错误包装文字。

每条 AI 素材记录模型、提示词、参考图、时长、用途和质检结论。检查乱码、肢体异常、角色漂移、动作不连贯和错误商品外观。

### Step 5：完成旁白、配音和 ASR

1. 先定稿旁白；
2. 生成或读取真实 VO；
3. 对最终 VO 运行字幕识别；
4. 以字级/句级时间戳安排镜头、字幕、花字和音效；
5. 再把总时长收敛到约 30 秒。

禁止把“每秒几个字”的估算当最终时间轴。

如果 VO 过长，优先删重复修饰词，不简单加速到难以听清。S05 保留短呼吸位，S07 三连信息保持节奏紧凑。

### Step 6：预处理素材，但不烧死创意层

允许：

- 裁切入点、去糊帧；
- 统一 1080×1920、30fps 和可编辑编码；
- 预制必要慢放版本；
- 去除 AI 视频偷带的音轨；
- 抽离现场原声；
- 制作无字竖版商品卡和无字 CTA 底图；
- 补齐 BGM 长度。

禁止预烧：

- 字幕、关键词、三连卖点；
- CTA 和免责声明；
- 剪映可以实现的推拉运镜；
- 剪映可以实现的文字进出场动画。

存在源入点时，优先预裁成 `source_start=0` 的标准 clip，避免关键帧被源入点推出片段。

### Step 7：生成本次唯一真源配置

每次建立独立项目：

```text
project/
├── edit_plan.json
├── 剪辑逻辑.md
├── analysis/
│   ├── 素材清单.json
│   ├── 素材盘点.md
│   └── 素材缺口表.md
├── assets/
│   ├── source/
│   ├── ai/
│   ├── clips/
│   ├── cards/
│   ├── vo/
│   └── audio/
├── scripts/
│   ├── prep_clips.py
│   ├── build_draft.py
│   └── verify_draft.py
└── draft_ops.json
```

`edit_plan.json` 至少包含：

- 商品信息与合规来源；
- S01–S09 镜头功能；
- 每镜素材来源：用户视频 / 用户图片 / AI 生成；
- 实际入点、时长、速度、运镜；
- VO 与 ASR 时间；
- 字幕、关键词、三连卖点和 CTA；
- 音效与 BGM；
- 草稿字体、颜色、坐标、动画和轨道；
- AI 生成记录。

`剪辑逻辑.md` 必须说明本次如何套用固定风格、哪些地方因商品特性而改写、哪些素材未使用及原因。

### Step 8：从零新建并装配剪映草稿

每次创建新的草稿，不修改上一商品的草稿。

装配前完成文字选型（见 `references/文字视觉规范.md`）：

- 先查看实际字体字形，优先沿用优设标题黑、抖音美好体、得意黑的角色分工；不可用则预览同气质字体并记录替代，不静默回退系统字体。思源等正文体主要用于小字说明。
- 对主字幕、关键词、三连卖点、CTA分别预览描边和阴影；主要原生文字层必须实际写入非零描边及投影，不能仅主字幕有阴影。遵循模板中的 `draft.text_defaults`，换后端先校准参数。
- 发现并检查 `get_text_template_previews`，看真实资源后用 `add_text_template` 在至少2处强调位置装配剪映文字模板，按需用于钩子、英雄、卖点或CTA。不能把手写文字样式称为剪映模板。资源不可用时记录原因并以原生分层文字替代。
- 已选模板登记到 `draft.text_templates`；ID来自实际预览，槽位数、方向、中文长度和时间范围必须匹配。模板负责的同一句普通花字需移除，避免叠字；模板内部可编辑程度以实际资源为准。
- 保存 `analysis/文字视觉选型.md`，执行时不能只读 `example.json` 的用户输入而跳过本节固定美术规范。


推荐轨道：

```text
01主视频
01b叠层/转场
02字幕
03关键词
04三连卖点
04b卖点副标
05信任状
06结尾卡·1…N
07常驻标注·1…N
10配音
10b现场原声
11音效
12BGM
```

装配顺序：

1. 主视频与商品图片；
2. 运镜关键帧；
3. 字幕和关键词；
4. 三连卖点与副标；
5. 信任状和结尾卡文字；
6. AI/广告说明；
7. VO、现场原声、SFX、BGM。

同屏文字分别占轨。结尾卡采用“无字底图＋独立文字层”，不能整张带字烧死。

### Step 9：路径策略

最终同机剪映草稿：

- 使用本地绝对路径；
- 写入前检查视频、图片、配音、音效、BGM 全部存在；
- 覆盖 `video_url(s)`、`image_url(s)`、`audio_url(s)`；
- 禁止把相对路径直接写进草稿。

云端预渲染：

- 后端不能访问本地文件时，临时上传预览所需素材；
- 预览草稿与最终本地草稿的媒体策略分开；
- 不要因为云预览需要远程 URL，就破坏最终草稿的本地素材引用。

### Step 10：预览、查询、校验、导出

至少检查三个关键区间：

- 0–4 秒微观钩子；
- 三连卖点信息最密集处；
- 结尾 CTA。

检查：

- 小怪与微观世界是否统一；
- S01–S04 是否形成清晰因果和爽点；
- AI 到实拍的切换是否自然；
- 商品包装是否真实可读；
- 字幕和花字是否遮挡主体或出框；
- 三连信息是否真实且节奏清楚；
- 主画面 0 秒开始并连续覆盖全片；
- 运镜关键帧成对且位于片段内部；
- VO、SFX、BGM 是否覆盖正确；
- 所有最终媒体路径是否为存在的本地绝对路径。

复杂写入后必须查询草稿实际结构。用户已经明确“直接做好/交付草稿”时，完成验证后可执行导出入队。

## 七、固定文案公式

这些是功能公式，不是固定台词。

### S01 钩子

```text
“你以为【普通动作】就够了？【问题】还在！”
“别再只用【普通方法】了，【痛点】根本没走。”
“镜头放大后才知道，你的【部位/物体】里藏着什么。”
```

### S02 失败反讽

```text
“【普通方法】一来，它们反而【滑稽动作】。”
“看着像处理了，其实【核心问题】还黏在那里。”
```

### S03 英雄登场

```text
“闪开，【产品能力】来了！”
“这次换【核心能力】上场。”
```

### S04 爽点闭环

```text
“【动作词】住【问题】，再把它【清除/隔离/修复】。”
```

### S06 商品落地

完整说出品牌和商品名，不用夸张功效词替代真实品名。

### S07 三连卖点

每段只保留：

```text
【成分/能力名】＋【用户能理解的一句解释】
```

### S09 CTA

- 有用户确认活动：使用真实价格/优惠；
- 无活动信息：使用“点头像看看”“到详情页了解”“带走这支”等保守表达。

## 八、可编辑草稿规范

### 字幕与关键词

- 主字幕：白字＋深色描边；
- 关键词：黄色或品牌强调色，独立轨；
- 行内高亮不稳定时使用双层字幕；
- 双层拼接困难时宁可整句字幕，不强行高亮。

### 三连卖点

- 大字名称和小字解释分轨；
- 每段约 2.0–2.8 秒；
- 使用弹入、二段缩放或轻推入；
- 动画与 whoosh/pop 对齐；
- 不使用一张不可编辑 PNG 代替全部卖点文字。

### 运镜

- AI 奇观段以轻推近为主；
- 英雄登场可更快推近；
- 商品和包装需要可读时减少运动；
- 图片使用轻推近或轻拉远，不能静止到像 PPT；
- 每次运镜至少两个 `uniform_scale` 关键帧，并处于片段安全区。

### 结尾卡

- 背景无字；
- 品牌、商品名、核心人群、CTA、卖点摘要、免责声明分别为原生文字；
- 用户没有价格和赠品信息时不留虚假价格占位符；
- 所有同屏文字分轨，避免片段重叠报错。

## 九、关键防错规则

1. **不要索要新参考视频。** 本技能本身就是固定参考风格。
2. **不要重新做参考片拆解。** 直接使用本技能固化的 S01–S09 结构。
3. **不要复用旧商品素材。** 每次用本次用户输入重新生产。
4. **不要用 AI 冒充真实商品包装。** 商品正式露出优先用真实素材。
5. **不要编造成分、价格、优惠、功效、排名或认证。**
6. **不要按字数估最终时间轴。** VO 完成后跑 ASR。
7. **不要先把字幕和花字烧进视频。** 创意层保留在剪映草稿。
8. **不要把相对媒体路径写进最终本地草稿。** 必须是存在的绝对路径。
9. **不要机械把用户所有素材塞入。** 按叙事价值选择，并记录未使用原因。
10. **不要把固定结构理解成固定台词。** 每次根据产品重写冲突与表达。
11. **不要把固定风格理解成完全固定时长。** 结构比例固定，切点服从真实语音。
12. **不要只看工具成功。** 必须查询草稿、检查路径和关键帧，并做关键区间预览。

## 十、完成标准

交付前必须满足：

### 风格一致性

- [ ] 有微观奇观钩子；
- [ ] 有统一的拟人痛点反派；
- [ ] 有普通方法失效的反讽；
- [ ] 有产品能力英雄登场；
- [ ] 有明确的动态爽点闭环；
- [ ] 有 AI 世界到真实实拍的落地；
- [ ] 有三连卖点/成分；
- [ ] 有真实信任状与 CTA。

### 本次商品适配

- [ ] 所有文案均针对本次商品重写；
- [ ] 商品、成分、功效和优惠信息有可靠来源；
- [ ] AI 镜头没有把错误包装当真实商品；
- [ ] 用户素材经过筛选而非机械全用；
- [ ] 未复用上一商品的素材、台词和时间戳。

### 草稿可编辑性

- [ ] 字幕、关键词、卖点、CTA、免责声明均为原生层；
- [ ] AI 视频、实拍、图片各自独立；
- [ ] VO、现场原声、SFX、BGM 分轨；
- [ ] 运镜使用草稿关键帧；
- [ ] 结尾卡为无字底图＋独立文字；
- [ ] 最终媒体均引用存在的本地绝对路径。

### 验证与项目文件

- [ ] 已保存本次 `edit_plan.json`；
- [ ] 已保存本次 `剪辑逻辑.md`；
- [ ] 已保存素材盘点、缺口表和 AI 生成记录；
- [ ] 已查询草稿画布、时长、轨道和素材结构；
- [ ] 已检查开场、三连卖点和结尾 CTA；
- [ ] 用户明确要求交付后才导出入队。

## 十二、后续迭代

- 用户说“换一个商品再做一条”：创建新项目、新草稿，继续使用本技能固定骨架。
- 用户只改文案、字体、颜色、动画或 CTA：优先增量修改当前草稿，不重建 AI 镜头。
- 用户更换核心卖点：检查是否影响 S01–S04 的冲突逻辑；若影响，重新生成对应 AI 镜头。
- 用户更换 VO：重新生成 VO、跑 ASR，并重排字幕、镜头切点和音效。
- 用户提供更多实拍：优先加强 S05–S08 的真实证据，不改变前段微观英雄叙事。
- 用户明确要求另一种参考风格：停止使用本技能，切换到通用参考片复刻技能；不要污染本技能的固定风格定义。
