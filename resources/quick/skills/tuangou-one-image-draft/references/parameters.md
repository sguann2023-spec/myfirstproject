| 项 | 值 |
|---|---|

| 正片时长 | 9.1s（= 口播 9.0s + 0.1 收尾） |
| 分镜源 | minimax-h3 输出 1440×2560（同为 9:16 → `scale=1` 即满幅无黑边，已预渲染确认） |

## 坐标换算（最容易踩）

`transform_*_px` 的系数是 **0.5**，不是画布像素：

```
transform_y_px = (960 - 目标Y像素) * 2      // 顶部标题 Y=180 → 1560
transform_x_px = (目标X像素 - 540) * 2      // 箭头 X=185 → -710
```

不标定就会出现「写了 790 却落在画面 29% 高度」。

## 字体与文字模版（每次预渲染选择）

历史验证过的字体可作为候选起点：顶部标题用汉仪英雄体；同步字幕/规则小字用抖音美好体；其他候选包括喜鹊万人造字、站酷仓耳渔阳体_W04、云魅手书、Aa狂派手书。它们不是固定结果，也不作为用户输入。

每次必须从剪映当前可用字体中选择至少两套候选，在真实背景上预渲染开场、价格爆点和结尾三个关键时刻。最终把选中的字体写入 `prerender_calibration.fonts.title/sub/note/promo`。

**价格爆点必须使用剪映文字模版**，不能使用普通字体层代替；至少比较两个模版或同一模版的两个合理缩放。配色可从白 `#FFFFFF`、红 `#E8000D`、黑 `#000000`、黄 `#FFE600`、棕 `#7A2E00` 起步，再按预渲染结果调整。
描边宽度：标题 6 / 字幕 5 / 爆点 11 / 加码 9 / 小字 4，alpha 均为 1。

## 阴影（v2 起：所有手调文字层必带）

统一 `shadow_color=#000000`、`shadow_smoothing=0.3`；`modify_text` 对 `shadow_*` 可靠生效。

| 层 | alpha | distance | angle |
|---|---|---|---|
| 顶部标题 | 0.5 | 5 | 45 |
| 同步字幕 | 0.55 | 5 | 45 |
| 规则小字 | 0.55 | 4 | 45 |
| 价格爆点 | 0.6 | 10 | 90 |
| 加码点 | 0.55 | 8 | 90 |

模版层（开场花字、结尾 CTA）**不加**阴影：模版资源包自带效果，再叠会和它的描边打架。

## 进场动画

| 层 | intro_animation | duration |
|---|---|---|
| 顶部标题 | 向上露出 | 0.4 |
| 同步字幕 / 规则小字 | 渐显 | 0.2 / 0.25 |
| 价格爆点 | 弹入跳动 | 0.35，rotation -3 |
| 加码点 | 波浪弹入 | 0.35，rotation -6 |

`add_image` **不支持** `intro_animation`（返回 `UNSUPPORTED_ANIMATION`）。

## 文字模版

| 位置 | 要求 |
|---|---|
| 开场由头 | 可用文字模版或手调文字，预渲染后选择 |
| 价格爆点 | **强制剪映文字模版**；比较至少 2 个候选模版或缩放 |
| 结尾 CTA | 模版或手调效果均可；比较候选后确定 |

`scale` 围绕自身中心缩放，改缩放不改锚点位置。选中结果写入 `prerender_calibration.templates`、`fonts` 和 `scales`。若模版因本机缓存资源无法预渲染，应换可预渲染模版；价格爆点不得回退成普通文字。

## 时间与音效规则

| 规则 | 说明 |
|---|---|
| 一切时间以 ASR 为准 | 对生成的口播跑 `subtitle-recognition`，取字级时间戳；禁止按字数估时长 |
| whoosh | 每个文字层进场**前 0.04s**，0.6s |
| ding（收银+金币） | 只给钱点：价格爆点、加码点各一次，1.1s |
| pop | 轻字幕进场，0.4s |
| 环境声 | 全片铺底，淡入 0.5 / 淡出 0.8；换品类换音色（烧烤=滋滋、奶茶=冰块、咖啡=蒸汽） |
| 切点 cut | 由 ASR 得到的第一个价格爆点进场时间减 0.04s 自动计算，叠化 0.3s；不是用户输入 |
| CTA | 最后 1.0s |
| 规则小字 | 价格点起 → 加码点止 |

## 电平（volume 参数不生效，只能烘进文件）

实测 mean / peak（dB）：

```
口播   -10.5 / -0.4        BGM   -17.6 / -0.3        环境   -21.9 / -1.0
whoosh -27.1 / -8.4  → +5dB 后 -21.6 / -2.9
pop    -31.2 / -9.8  → +6dB 后 -24.8 / -3.4
ding   -43.4 / -19.3 → +14dB 后 -29.0 / -4.8   ← 不抬就听不见钱点
```

口播/BGM/环境三者天然梯度合理（BGM 比人声低 8dB），一般不用重烘。

### 增益要每次反算（2026-10-28 复测，见 pitfalls#17）

`bake_sfx.sh` 里写死的 +14/+6/+5 只对历史那批素材成立。正确做法：先 `volumedetect` 测本次**原始** mean，再按 `gain = 目标mean − 原始mean` 加，最后用 `astats` 的 `Flat factor` 确认没削顶。

| 轨 | 目标 mean/peak | 本次原始 | 实得增益 | 成品 |
|---|---|---|---|---|
| 口播 | -10.5 / -0.4 | -9.2 / -0.2 | -1dB | -9.7 / -0.7 |
| BGM | -17.6 / -0.3 | -15.5 / -0.2 | -2.5dB | -17.5 / -2.3 |
| 环境 | -21.9 / -1.0 | -45.9 / -15.6 | +16dB→compress→+4dB | -21.9 / 0.0(未削顶) |
| whoosh | -21.6 / -2.9 | -22.4 / -8.4 | +1dB | -21.0 / -6.9 |
| pop | -24.8 / -3.4 | -22.6 / -2.5 | -2dB | -24.1 / -4.0 |
| ding | -29.0 / -4.8 | -32.8 / -7.7 | +4dB | -28.3 / -3.4 |
