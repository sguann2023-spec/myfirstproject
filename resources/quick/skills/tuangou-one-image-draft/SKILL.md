# 一张图生成餐厅引流团购视频

> 旧名「团购一张图出草稿」，2026-10-28 改名，参数与流程不变。

把「一张图 + 一段促销文案」变成一条可直接打开继续改的剪映草稿（1080×1920，约 9.1s，画面零文字，文案/花字/音效全在轨道上）。
本技能是 1986串串 复刻项目的沉淀，参数已预渲染标定，坑已踩过。

## 输入契约

```yaml
required:
  image: 一张门店/菜品图（本地绝对路径或公网 URL）—— 唯一视觉输入
  prompt: 用户点示例后自动带入的完整提示词；里面已经包含示例文案与成片要求
```

用户不需要填写参考视频、固定素材、切点、CTA 缩放或工程名：
- 本技能**只复刻已固化的 1986 串串团购片结构与风格**，不接受其他参考片，也不做新风格逆向。
- 每次都根据唯一主图重新生成画面与音频，不提供“固定素材复用”输入。
- 切点由本次口播 ASR 与价格爆点进场时间自动计算，落在价格爆点前约 0.04s。
- 字体、文字模版及缩放都不是用户参数，也不固定为某一套；技能从剪映可用字体/模版中选择候选并多轮预渲染。
- **价格爆点必须使用剪映文字模版**；开场由头和结尾 CTA 可使用文字模版或预渲染证明效果更好的手调文字。
- 预渲染比较的是整套文字设计，而不只是 CTA 缩放：至少覆盖标题/字幕可读性、价格爆点模版、结尾 CTA，并检查层级、遮挡和出框。
- 工程名从提示词中的店名自动生成；无法可靠提取店名时使用“餐厅引流团购视频_日期时间”，不向用户索取。

缺图必须问用户要，不能凭空生成店景。提示词中的示例文案可由用户直接在自然语言里改写，但不额外显示文案分组表单。
开始前先输出 8 步执行计划，并说明会产生付费调用（约 首帧 90 + 分镜 300 + 音频 138 + 预渲染 8~40 点）。

## 时间轴骨架（先占骨架，再填字）

```
t=0.00 ─────────────────────────────────────────── t=9.10
[常驻] 顶部店名标题            白+红描边+阴影       0.00 → 全片
[同步] 字幕1 钩子句 / 字幕2 引导句 / 字幕N 收尾句   跟随口播 ASR
[爆点] 花字1 由头  → 价格爆点（剪映文字模版） → 花字3 加码点   逐条进场，互不重叠
[说明] 规则小字 ≤2 行          价格点起 → 加码点止
[贴片] 箭头贴纸                与价格点同步，指向团购锚点
[爆点] 结尾 CTA（模版或手调效果，预渲染后确定）      最后 1.0s
```

画面：两段 minimax-h3 分镜（0→cut，cut→end），中间「叠化 0.3s」，画面内不得出现任何文字。
声音：口播 + BGM + 品类环境声 + whoosh（文字进场前 0.04s）+ ding（只给钱点）+ pop（轻字幕）。

## 执行流程（8 步，逐步汇报进度）

1. **读图 + 补文案**：确认图的品类/风格；9 句文案齐了才继续（`references/copy-formula.md`）。
2. **生成 2 张首帧**：`image__generate_or_edit_image`（seedream-4.5，1440×2560，把用户图放进 `referenceImages` 锁风格）。分镜1 = 中景人物+满桌+动作起手；分镜2 = 更大特写+夸张表情。minimax-h3 允许真人脸，**不需要再去脸**。
3. **生成 2 段分镜**：`video__generate_video`（`model:"minimax-h3"`, `generation_mode:"first_frame"`, `resolution:"1440x2560"`, `gen_duration:5`, `composeDraft:false`）。抽 3 帧质检人脸/凭空文字/动作；`ffmpeg -an -c:v copy` 剥掉 AI 偷偷塞的音轨。
4. **生成 6 条音频**：`seed-audio__generate_seed_audio`（口播逐字台词纯人声、BGM、whoosh、ding、pop、品类环境声），然后 `bash scripts/bake_sfx.sh <src> <out>` 把电平烘进文件。
5. **ASR 对齐**：对**生成的口播**跑 `subtitle-recognition__submit_subtitle_recognition_task`，取字级时间戳填 `timing`（subs/promos/noteRange/ctaRange/whooshAt/popAt/dingAt）。**禁止按字数估时长**——这是整条管线唯一的时间真值来源。
6. **上传素材**：9 条媒体全部 `file-upload__upload_file_to_oss` 拿签名 URL（本地路径会写坏素材记录）。
7. **多轮预渲染选字效**：每次都做，且不是只检查 CTA。另建若干个 **≤5s** 预览草稿，在本次真实背景上比较至少 2 套文字设计：
   - 标题/同步字幕/规则小字：比较剪映中的不同字体或样式，确认可读、描边与阴影有效；
   - 价格爆点：必须比较至少 2 个剪映文字模版或同模版的不同合理缩放；
   - 结尾 CTA：比较模版/手调方案及合理缩放。
   用 `draft-render__render_draft`（单次失败可重试 2~3 次）并抽帧，按“层级明确、可读、不遮主体、不出框”选择。把每层候选、选中模版/字体/缩放和结论写入 `prerender_calibration`；不得沿用固定 CTA 或固定字体。
8. **装配 + 导出 + 校验**：
   - `node scripts/plan.mjs spec.json > plan.json`（坐标/字号/描边/阴影/动画全部由脚本算，模型不要手算）
   - 看自检输出：`爆点重叠`、`不是云端 URL`、`规则小字超 2 行` 必须先修
   - codemode 顺序回放 `plan.json` 的 `calls`，逐条记录 `step / ok|error`
   - `draft-download__export_draft` → `python3 scripts/verify_draft.py <本地工程目录> --cta-scale <本次预渲染选中值>`，PASS 才算交付

## 硬规则（违反必翻车，细节见 `references/pitfalls.md`）

1. 所有进草稿的媒体**必须是云端 URL**，先上传再 add。
2. `modify_video` 不能改时长/换源（`duration` 被当**微秒**写）→ 一律 remove + add；随后必须把箭头 remove + add **复位 z-order**。
3. 音频 `volume` 参数**全链路不生效**（恒 ~1.02–1.12）→ 混音电平只能烘进文件；ding 不抬 +14dB 就听不见钱点。
4. `add_image` / 文字模版的 `scale` 是**倍数**：0.20 表示 20%，写 20 会白屏。
5. 价格爆点必须使用本次预渲染选中的剪映文字模版；标题、字幕、规则小字和 CTA 的字体/模版/缩放也以本次预渲染为准。若模版因本机缓存资源无法预渲染，换可预渲染模版；价格爆点不能退回普通文字。
6. `render_draft` 只吃 ≤5s 草稿，正片需拆成关键区间预览；至少检查开场、价格爆点、结尾三个时刻。
7. 所有普通文字层必带描边和阴影；使用剪映内实际可用且预渲染效果合适的多种字体，不再把某几个字体或“禁用字体名单”写死为用户输入规则。

## 交付汇报模板

完成后按这个结构回复，缺一不可：

- 剪映工程名 + 本地路径 + 体积 +（时长 / 画幅 / fps / 轨道数）
- 画面：2 段分镜的内容与落点、箭头贴纸
- 文字层表：层 / 内容 / 时间 / 字体+字号 / 样式（描边、阴影）/ 进场动画
- 音效表：轨 / 落点 / 时长 / 实测电平
- 预渲染比较表：关键时刻 / 候选字体或模版 / 缩放 / 结果 / 最终选择
- `verify_draft.py` 的 PASS/FAIL 结果
- 与本技能固化风格骨架的差异及理由
- 本次点数成本

## 可解析样例输入

同目录 **`example.json`** 是市场侧可解析样例。用户侧输入只保留：执行模型、完整提示词、1 张主参考图。

参考片结构、两段分镜规则、ASR 对齐、切点计算、音频生成、整套文字效果预渲染选择、工程自动命名、装配与校验都属于技能内部行为，不暴露为表单参数。`display_info` / `jump_url` 仅用于说明本技能所固化的来源风格，不代表可以传入新的参考视频。

## 迭代与复用

- 用户提修改（换字体/改缩放/加阴影/换画面）→ 优先用 `modify_text` 在原草稿增量改，**不要重建草稿、不要动时间轴**；改完重跑 `verify_draft.py`。
- 换商家：用户只换主图，并可在完整提示词里自然语言改店名与优惠内容；技能重新生成画面、口播、音效并跑 ASR，固化的风格骨架不变。
- 每次自动生成唯一工程名、自动计算切点，并通过多轮预渲染重新确定普通文字字体、价格爆点模版和 CTA 效果；这些都不是用户输入。
- 每次跑完把新踩的坑追加进 `references/pitfalls.md`，把新标定值追加进 `references/parameters.md`，让技能自更新。
