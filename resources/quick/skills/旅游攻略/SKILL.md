# 旅行混剪

这是一个旅行短视频制作技能。默认只需要用户给出旅行主题和旅行素材视频，技能先按攻略口播风格生成文案，再按素材内容和时间轴生成一套竖屏旅行混剪视频。

## 限制

- 默认输入必须有旅行主题和旅行素材视频。主题可以是目的地、天数、人群、预算或玩法，例如“潮汕五天四晚亲子游”。
- 旅行素材至少 1 条，优先使用视频；图片也可以混用。素材可以是本地图片或者视频，也可以是视频、图片链接；素材总个数不超过50，总时长不超过20分钟。
- 必须由用户从外部输入 API Key；所有远程请求和脚本都必须使用用户本次外部传入的原始 API Key，并通过参数显式传入，不能读取环境变量 `VECTCUT_TOKEN`，不能使用历史缓存值或手动改写后的值。
- 用户没有给主题时，先问主题；没有给旅行素材时，先问素材。缺任一项时不创建草稿、不生成配音。

## 执行步骤

1. 检查限制。必须先确认有旅行主题、旅行素材和外部输入的 API Key；素材至少 1 条、不超过 50 条、总时长不超过 20 分钟。缺主题、缺素材或缺 API Key 时先询问；超过限制时直接停止并说明原因，不创建草稿、不生成配音。
2. 生成攻略口播文案。用户没有给口播文案时，先根据主题自动生成文案；文案参考这个风格：“潮汕什么时候最好玩？当然是现在！收藏好这份攻略，人均八百玩转五天四晚！今天带的是李哥一家三口，他们是刷到视频直接私信来的。我安排的行程不赶不累，吃住全包，景点全打卡。来看看我们怎么玩的。第一站，菩提禅寺，潮汕版布达拉宫，门票停车全免费。第二站，南澳跨海大桥，海上巨龙，一眼望不到头。第三站，长山尾灯塔。新人扎堆拍婚纱的高颜值打卡地。第四站自然之门，全国唯一海岛北回归线标志塔。第五站青澳湾，2400米金色沙滩。踩上去软的像彩云。如果你也想来潮汕，评论区扣攻略，我发你详细行程。”实际生成时替换目的地、人群、天数、预算和站点，不要照抄“潮汕”“李哥”“一家三口”等示例信息；没有精确信息时不要硬编数字。文案默认 180 到 280 个汉字。
3. 根据口播文案生成一个音频。使用规则看 `references/tts.md`；默认使用旅行混剪音色，API Key 必须使用用户本次从外部传入的原始值，并通过脚本参数显式传递，不能读取环境变量或使用缓存值；成功后必须取得口播音频 URL，没有音频 URL 时停止。
4. 识别字幕。使用规则看 `references/subtitles.md`；固定使用 LLM 档位，API Key 必须使用用户本次外部传入的原始值，并通过脚本参数显式传递，成功后必须取得完整文本和分段字幕时间轴，没有字幕分段时停止。
5. 识别图片素材内容，整理提供的本地图片、图片链接素材，对图片先识别内容并转成简洁文字描述，再进入后续分析。
6. 理解视频素材内容。先判断视频是不是本地文件；如果是本地文件，先用 `references/video-upload.md` 和 `scripts/upload_video.py` 上传成临时视频链接，再继续理解。随后按 `references/video-understand.md` 和 `scripts/understand_video.py` 理解视频；上传、理解和轮询都必须使用用户本次外部传入的原始 API Key。这个步骤支持单视频和批量视频链接，批量时可以一起传 `fps_list`，默认由脚本按视频时长自动分配抽帧率，短视频帧率更高、长视频更低，整体目标控制在 200 到 300 帧左右。成功后必须得到每条视频的文字理解结果，没有理解结果时停止。
7. 生成分镜计划。把第 4、5、6 步得到的字幕时间轴、图片描述和视频理解结果交给模型生成 1 套分镜计划；先以字幕时间轴为主轴，再让图片和视频内容向主轴靠拢，计划必须覆盖完整时间轴、只使用真实素材索引，且时间片段必须完全连续：首段 `start=0`，每段 `start` 必须等于上一段 `end`，最后一段 `end` 必须等于总时长，不能有空隙、负时长或重叠，每个空镜大概 3 到 5 秒。解析模型分镜后只允许做轻量边界校正：例如把最后一段补齐到总时长，或把毫秒级相邻边界对齐；不得因为很小的尾差丢弃语义匹配更好的计划。
8. 创建草稿。使用 `references/create-draft.md` 和 `scripts/create_draft.py`；必须把用户本次外部传入的原始 API Key 作为脚本参数传入。草稿固定竖屏，封面可选，成功后必须取得草稿 ID 和草稿 URL。
9. 添加智能字幕。先为口播草稿从固定字幕模板里随机选一个，再用 `references/smart-subtitle.md` 和 `scripts/generate_smart_subtitle.py` 添加到草稿；必须把用户本次外部传入的原始 API Key 作为脚本参数传入。
10. 添加画面素材。先用图片描述找图片，找不到就用 `references/video-capture.md` 和 `scripts/capture_video_timestamp.py` 从视频里抓时间戳，再按 `references/add-materials.md` 把 `start`、`end`、`target_start` 带给 `add_image` 或 `add_video`；`start/end` 是截取源视频或源素材的时间片段，`target_start` 是草稿里的目标开始时间，不能混用。画面定位和所有素材写入都必须使用用户本次外部传入的原始 API Key。写入前必须按分镜排序并校验草稿目标时间轴完全连续：第一段 `target_start=0`，后一段 `target_start` 必须等于前一段 `target_start + 有效显示时长`，最后一段必须覆盖到总时长；发现空隙或重叠时先修正时间轴，无法修正就停止，不写入不连续素材。按分镜连续添加视频、图片和图片缩放关键帧；视频片段之间必须加转场，转场写在前一个视频片段的 `add_video` payload 上：如果前后画面没有明确叙事、地点、主体或动作连续关系，用 `翻页`；其他边界用 `左移`；最后一个视频片段不加转场。发生素材轨道冲突时先修正时间轴，只在明确轨道重叠错误时重试备用轨道。添加视频的时候音量为-60。
11. 添加背景音乐。背景音乐从 `references/bgm.md` 里随机选一个，再按 `references/add-audio.md` 写入草稿；所有音频时长查询和写入都必须使用用户本次外部传入的原始 API Key。背景音乐轨道为 `bgm_audio`，音量设置为 `3`。
12. 添加口播配音。把第 3 步生成的配音音频按 `references/add-audio.md` 添加进草稿，纯素材模式不添加口播音频；配音轨道为 `speech_audio`，音量设置为 `20`，`target_start` 默认为 `0`。
13. 最终校验。使用 `references/query-script.md` 和 `scripts/query_script.py` 查询草稿脚本内容，必须把用户本次外部传入的原始 API Key 作为脚本参数传入；检查是否有空隙、是否连续、字幕、配音、背景音乐是否都加上了。
14. 返回结果。展示思考切片的关键环节，不展示请求回包的具体细节。

## 交付标准

只有草稿创建成功、素材轨道连续、字幕或关键词写入符合模式要求、背景音乐处理完成或明确跳过，并且每个远程写入响应都通过校验后，才能报告完成。
