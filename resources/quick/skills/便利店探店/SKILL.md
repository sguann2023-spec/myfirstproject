# 便利店探店口播模板

这是一个面向便利店探店内容的漫味粗标风格口播剪映草稿技能。默认以用户口播视频为主线，使用去气口后的统一时间线，生成 1080x1920 竖屏草稿；可选图片/视频素材会根据文案语义做背景画中画、视频素材 PIP、模糊特效和关键词文字模板。

## 输入限制

- 必须有口播视频 URL 和用户本次提供的 VectCut JWT/API token。
- 口播视频至少 1 条；当前技能一次只生成 1 个草稿。
- 素材可选；支持图片或视频 URL。没有素材时只生成口播主视频、标题、字幕、BGM 和关键词文字模板。
- `remove_silence` 默认开启；只压缩前中段的气口，原口播视频尾部静音必须保留，并作为无字幕尾段接回统一时间线。
- 缺少口播视频或 token 时先询问，不创建草稿。

## 禁止事项

- 不把视频 URL 当普通聊天文本交给 LLM 猜内容；视频素材必须走视频分析接口。

## 主体流程

1. 规范化输入，确认口播视频、token、可选标题/文案、可选素材列表。
2. 获取口播视频源时长，提交 ASR/去气口，生成唯一时间线；去气口后把原视频末尾未使用的静音尾段接回，后续所有轨道都以该时间线为准。
3. 根据文案生成两行标题；标题固定展示 3 秒。
4. 创建 1080x1920 竖屏剪映草稿，草稿名使用标题和时间戳。
5. 根据去气口时间线添加口播主视频分段；禁止直接把原始口播视频整段铺满。
6. 用 `/cut_jianying/add_text` 逐条添加毛笔行楷字幕；不调用智能字幕接口。
7. 如果有素材，先逐条识别素材类型并分析全部素材。图片必须先由当前 Codex/本地视觉模型读取；本地分析不可用、失败或结果为空时，脚本自动调用 VectCut LLM 的 `image_url` 接口兜底。视频逐条走 `video_detail` 一类视频分析接口。图片和视频分析摘要必须传入匹配器，不能按文件名、URL 或尺寸猜测内容。
8. 让 LLM 根据文案和全部素材摘要选择一个最强匹配的背景画中画窗口；背景素材可以是图片或视频，素材全屏展示，口播视频在右侧中间做 PIP。优先匹配门店外观、货架陈列、冰柜区域、收银台或探店动线相关画面。每个草稿最多添加 1 个背景画中画效果，窗口最长 3 秒，不得进入开头 2 秒或结尾 2 秒保护区。
9. 让 LLM 根据文案和全部视频素材摘要选择一个最强匹配的视频素材 PIP + 模糊窗口；每个草稿最多添加 1 个该效果，且不能复用背景画中画已经使用的素材。匹配必须依据 `video_detail` 的门店区域、商品类别、新品卖点、价格促销或试吃试喝反馈语义，不能按素材顺序套用前几句文案；成功取得分析结果但没有语义匹配时直接跳过，只有分析失败或结果为空时才允许使用明确标记的低置信度兜底。该窗口不能与背景画中画重叠，最长 3 秒，且不得进入开头 2 秒或结尾 2 秒保护区。
10. 添加 BGM，覆盖包含尾部静音的草稿总时长，音量不能盖过口播。
11. 让 LLM 根据文案选择少量促销/自评关键词，调用文字模板添加；同一模板每分钟最多 2 个。
12. 写 JSONL 调试日志，记录 LLM 请求、素材分析、最终轨道 items 和 VectCut API 响应。
13. 查询或核对草稿结构，确认标题、字幕、视频、素材、特效、BGM 和关键词模板都落在统一时间线上。
14. 返回草稿 ID、草稿链接、去气口状态、素材效果数量、关键词数量和日志路径。

## 脚本

执行脚本放在 `scripts/koubo_c6f1_atomic_task.py`。脚本必须按本 skill 的原子接口流程实现，不得导入或调用既有模板总函数。

时间线实现必须保留原视频尾部静音；全部素材必须在写入前逐条完成分析和匹配。便利店探店场景下，素材匹配优先围绕门店环境、货架分区、饮料零食新品、价格标签、促销信息和试吃试喝反馈。每个素材画中画窗口必须在写入 API 前再次校验开头/结尾 2 秒保护区和全局互斥窗口，模型返回越界或重叠时间时拒绝或调整到同一匹配句内的合法窗口。

## 交付

只交付剪映草稿，不渲染成片视频。完成时返回草稿 ID、草稿链接、是否去气口、字幕数量、素材数量、背景画中画是否触发、视频素材 PIP + 模糊是否触发、关键词文字模板数量和调试日志路径。
