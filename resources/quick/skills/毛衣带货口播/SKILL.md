# 毛衣带货口播模板

用于生成以毛衣带货为主题的口播剪映草稿。默认以口播视频为主线，支持可选图片或视频素材，并输出 1080x1920 草稿。

## 使用方式

用户需要提供口播视频和 VectCut API Key；图片或视频素材为可选输入。多个素材按用户给出的素材列表依次处理。

## 默认流程

1. 获取口播视频信息并识别口播文案。
2. 生成去气口后的统一时间线。
3. 图片素材必须先由当前 Codex/本地视觉模型读取；本地分析不可用时由脚本自动调用 VectCut LLM 的 `image_url` 接口兜底，不能直接按文件名猜图。
4. 分析用户传入的视频素材。
5. 根据口播文案选择适合的素材效果点。
6. 写入口播主视频、素材预设或画中画、字幕、音频和 BGM。
7. 查询草稿结构并返回剪映草稿链接。

## 规则入口

素材效果按带货话术阶段选择：开场推荐、版型展示、上身效果、材质触感、搭配建议、价格福利或下单引导，优先使用毛衣整体图或上身图做画中画；说到软糯、厚实、亲肤、显瘦、垂感、针法、领口、袖口、细节做工等卖点时，优先使用细节图的图片+口播片段预设。两种效果仍不能在同一时间段叠加。

- VectCut 接口、预设、字幕和画中画参数见 [api-contracts.md](references/api-contracts.md)。

## 交付

只交付剪映草稿链接，不渲染成片视频。最终说明草稿 ID、ASR 模式、素材数量、各效果写入数量和关键 task id。
