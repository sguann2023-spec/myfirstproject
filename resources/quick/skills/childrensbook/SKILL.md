# 儿童绘本技能

当用户要“做一个儿童绘本故事”时触发。

## 执行方式

1. 检查主题
   如果用户没有提供故事主题，就先反问用户提供一个主题,例如怕黑的小兔子、勇敢的小狮子，再继续后面的步骤。

   如果信息不完整，默认：  

    - 中文
    - 3-6 岁
    - 8 页左右
    - 温暖、童趣、适合睡前或亲子共读
    - 主题优先用勇敢、分享、情绪管理、成长


2. 创建草稿
   先创建一个 `1080x1920` 的竖屏草稿。
   草稿名写成 `儿童绘本：` + 主题。
   创建成功后必须拿到 `draft_id`，拿不到就视为失败。
   输出结果示例：

   ```json
   {
     "success": true,
     "output": {
       "draft_id": "dfd_cat_1752305579_38e2e11b",
       "draft_url": "https://www.vectcut.com/draft/downloader?draft_id=dfd_cat_1752305579_38e2e11b"
     }
   }
   ```

3. 生成分镜文案
   根据主题一次生成整套绘本文案和分页内容。
   这一步要产出故事标题、完整文案、拆好的短句，以及 `6` 个左右的分页或分镜。
   文案要像绘本老师在讲故事，句子短一点、顺口一点，适合孩子听，也适合后面做配音。
   整个故事要有开头、推进、转折和结尾，整体气质要温暖、童趣、有成长感，不惊悚、不成人化。
   每一页都要写清楚页标题、本页文案、配图提示词和画面重点。
   配图提示词要能直接拿去生成图片，角色前后要一致，画面风格要统一，字幕内容也要能和分页文案对应起来。
   输出结果示例：

   ```json
   {
     "title": "不怕黑的小兔子",
     "script_text": "天一黑，小兔子就紧紧抱住小被子……",
     "sentences": [
       { "id": "s1", "text": "天一黑，小兔子就紧紧抱住小被子。" }
     ],
     "scenes": [
       {
         "title": "第 1 页",
         "narration": "天一黑，小兔子就紧紧抱住小被子。",
         "sentence_ids": ["s1"],
         "image_prompt": "温暖童趣的绘本插画风格，小兔子抱着被子坐在床上，夜色柔和，9:16 竖屏。",
         "visual_focus": "小兔子害怕夜晚的神情"
       }
     ]
   }
   ```

4. 生成配音
   把完整故事文案整理成更适合朗读的版本，再用豆包语音生成整段配音。
   这一步要把换行、过多停顿和太拖沓的标点稍微整理一下，让听感更像在讲故事，不要太慢。
   音色保持固定，整体感觉要温柔、自然，适合儿童绘本。
   成功后要拿到可以播放的配音链接，拿不到就视为失败。
   输出结果示例：

   ```json
   {
     "success": true,
     "model": "seed-audio-1.0",
     "url": "https://example.com/audio.wav",
     "text_prompt": "天一黑，小兔子就紧紧抱住小被子，轻轻问，妈妈，夜晚真的可怕吗？",
     "voice_id": "gv_2e601fae38484816adf8bf5c38b79393"
   }
   ```

5. 生成字幕
   用字幕模版 `asr_42da310c1e4347ddb2c96dd2a5d055c2` 给这段配音生成字幕。
   每一句字幕都要有对应的出现时间和结束时间，方便后面按时间去铺图片。
   要把明显无效的字幕去掉，只保留正常可用的字幕时间轴。
   如果最后没有成功拿到字幕时间轴，就视为失败。
   同时保留最新的草稿信息和草稿地址，方便后面继续处理。
   输出结果示例：

   ```json
   {
     "success": true,
     "status": "success",
     "output": {
       "draft_id": "dfd_cat_xxx",
       "draft_url": "https://www.vectcut.com/draft/downloader?draft_id=dfd_cat_xxx&is_capcut=0",
       "subtitles": [
         {
           "id": "sub_001",
           "text": "天一黑，小兔子就紧紧抱住小被子。",
           "start_time": 0.0,
           "end_time": 1.8,
           "target_track": "track_sub"
         }
       ]
     }
   }
   ```

6. 生成图片并写回最终视频草稿
   按每一页的文案和配图提示词，用 `gpt-image-2` 生成插图，分辨率要求9:16竖屏，并把图片放进最终视频草稿里。
   每一张图的开始时间和结束时间，都要和对应分镜的字幕时间戳对齐。
   第一张图必须从 `0` 秒开始，最后一张图必须接到最后一句字幕结束，整条主轨道要从开头一直铺满到结尾。
   中间不能留空白时间，也不能错位，每一张图都要和自己的分镜时间段对应上。
   前面的图片可以加一些自然的转场，最后一张通常不加。
   每张图生成成功后，都要拿到图片地址，并把最新草稿继续往下传。
   最后保留每一页对应的图片结果、时间位置和草稿信息。
   全部图片写回草稿后，要再调用 `query_script` 自查一次当前草稿状态，确认图片、字幕、配音和时间轨道都已经放对位置，整个结果确实满足需求。
   如果发现草稿里还有图片缺失、时间没铺满、字幕没对齐，或者最终效果和分镜不一致，就要继续修正，不能直接结束。
   这里返回的 `draft_id`，必须是前面刚创建并一路往下传的最终视频草稿；`start` 和 `end` 是这张图片写入草稿时使用的开始和结束时间戳。
   输出结果示例：

   ```json
   {
     "success": true,
     "status": "success",
     "result": {
       "draft_id": "dfd_cat_xxx",
       "draft_url": "https://www.vectcut.com/draft/downloader?draft_id=dfd_cat_xxx&is_capcut=0",
       "image": "https://example.com/image-1.png",
       "start": 0.0,
       "end": 1.8
     }
   }
   ```

7. 输出最终结果
   把整套结果整理出来，至少包括草稿编号、草稿地址、配音链接、字幕时间轴、分页内容，以及每一页对应的图片结果。

8. 下载草稿
   草稿制作完成后，直接用draft_download工具下载下来继续编辑。

## 输出格式

默认直接输出：

1. 标题
2. 适龄
3. 主题
4. 角色设定
5. `draft_id`
6. `draft_url`
7. 完整故事
8. 已经下载到剪映，去剪映里查看的提示
