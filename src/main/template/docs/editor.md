# 模版编辑器界面

最新数据格式见 [剪映结构模版](./draft-template.md)：materials 全局共享，
scenes → tracks → segments；以下旧元素字段说明仅适用于历史模型。
默认 JSON、添加素材和层级树已使用新结构，自动对齐在片段 auto_timing 中声明。

当前页面使用左侧层级树、右侧 JSON 编辑器、底部静态时间轴，不包含画面预览、
属性面板或播放功能。默认内容为用于演示时间编排的一个 scene、两个文字和一张图片。

## 使用方式

- 顶部四个按钮分别添加文字、图片、视频和音频。媒体通过本地文件选择框添加。
- 新元素放入选中的 scene；选择某个素材时，放入该素材所在 scene。
- 新元素使用独立 track_name 和 track_relative_index，target_start_time=0，省略 duration，默认填充所在 scene。
  相同名字的同类型内容共用轨道；排序值独立映射为后端 relative_index，不支持跨类型混排。
- 只编辑一个 Template JSON；根 timing_rules 声明时间关联，根 sources 声明素材映射。
  已移除“关联配置”标签。默认图片 start/end 与 text-2（Text-8L9）完整对齐。
- 右上角花括号按钮切换只读 Workflow，再次点击返回 JSON。
- 右侧“测试导出”编译当前文档、执行 Workflow，然后将返回的草稿提交到主窗口下载队列。
  按钮期间禁止重复提交；入队不是下载完成，最终进度与失败信息在主窗口查看。
  执行成功但导出入队失败时保留草稿 ID，再次点击同一文档只重试导出。
- 点击层级节点或时间轴片段，会选择对应元素并在 JSON 中定位。
- 同一 scene 的同一 track_name 合并显示；片段重叠时分行。层级树可以折叠。
- 时间轴显示所有片段的全局可见时间，复用 scene 解析器的截断和关联规则。
- 无效 JSON 保留当前输入，层级保留上次有效结构并标注，时间轴暂停展示，
  禁止添加素材及编译；修正后自动恢复。输入变动会清除旧 Workflow。

## 当前范围

- 图片与文字可转换为 Workflow，视觉适配仍遵守现有编译器的警告。
- 视频、音频目前仅支持 JSON 编辑和时间编排，不解析源媒体时长，不转换为 Workflow。
  包含这些元素时整次转换明确失败，禁止跳过它们输出不完整结果。
- 编辑状态仅保留在当前窗口，尚未接入保存或恢复。仅主动点击“测试导出”才执行 Workflow。
- 测试导出使用现有登录凭证与服务端接口，可能产生正常的服务消耗；不会自动重复执行失败请求。
- 界面 JSON 保持普通字符串；执行边界使用 inputs 变量引用保护文字、颜色和路径，
  防止后台把文字中的算式、引号或变量符号误作表达式。
- 文件选择不上传媒体，使用本地路径；远程后台访问素材仍需自行映射或上传。
- 新增元素使用 target_start_time=0；视频/音频还默认 source_start_time=0。
  target_end_time 可填秒数或 end；旧 time 已移除，包含该字段的 JSON 会明确报错。
  已打开窗口中的旧 JSON 需手动迁移；主进程更新后需重启应用。

## 代码与验证

- `editorModel.ts`：数据解析、层级、轨道布局、添加素材、编译调用。
- `sceneTemplate.ts`：共用时间语义；analyzeSceneTemplate 只解析时间，
  compileSceneTemplate 才校验素材和生成动作。
- `registerTemplateIpc.ts`：编辑器 IPC 与系统文件选择框。
- Page 只负责交互与展示，通过 IPC 调用主进程模型。

运行 `pnpm exec vitest run src/main/template` 验证编辑器模型及编译逻辑。
浏览器验证使用真实模型替代 IPC 传输，文件选择结果模拟；系统原生文件对话框与最终渲染需在客户端验证。
