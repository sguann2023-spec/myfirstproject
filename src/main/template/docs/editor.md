# 模版编辑器界面

最新数据格式见 [剪映结构模版](./draft-template.md)：materials 全局共享，
scenes → tracks → segments；track 为支持混排的逻辑轨道。
默认 JSON、添加素材和层级树已使用新结构，自动对齐在片段 auto_timing 中声明。

贴纸已对齐后台 `add_sticker_impl`：优先 `sticker_id`、其次 `resource_id`，
时间采用全局可见区间，轨道独立拆分并保留视觉层级。
`clip.transform/scale/rotation/alpha/flip` 支持静态与动态映射；批量条目使用
`{sticker_id: "资源ID"}`，中文目录名保留在 `input_labels`。
空 ID 可编辑但导出提示填写真实资源。
滤镜/特效支持 `add_filter`、`add_effect`，类型分别填写素材的 `filter_type`、
`effect_type` 后台枚举名称（兼容素材 `name`，不是数字资源 ID）。
滤镜 `intensity` 为 0-100；省略时原生 `value` 乘 100。特效 `effect_category` 为
`scene`/`character`，`params` 按后台顺序填写 0-100 数值或 null 数组。
原生 `adjust_params` 按 parameterIndex 和 min/max 转换百分比，再反转以匹配后台；
动态参数请使用 `params`。批量目录槽位使用 `filter_type`/`effect_type`。

当前页面使用左侧元素树、右侧 JSON 编辑器、底部可交互时间轴，不包含画面预览、
属性面板或播放功能。点击“新模版”先弹出选择框，选中后才打开独立编辑窗口，
不覆盖已打开窗口中的内容。

## 内置模版

- 空白模版（Empty template）：15 秒竖屏 Scene，无素材，可从顶部工具添加。
- 一句一图：三句话分别对应三张图片，每句默认 5 秒。图片片段的 `auto_timing.start/end`
  分别关联对应文字的开始和结束；修改文字 `target_timerange` 后，图片时间自动同步。
  父轨道包含三个 `type: "scene"` 子 Scene，每组内部的文字、图片各占一条独立轨道，
  文字位于对应图片上方。模版层只显示顶层 Scene，进入父 Scene 后显示三个组合片段，
  再进入任一组才显示该组的文字、图片两条轨道，不再把七行同时铺开。
  文字时间相对子 Scene；各组开启 auto_duration，后一组开始关联前一组结束。
  第一句时长从 5 秒改为 7 秒后，三组依次为 0–7、7–12、12–17 秒，总时长自动变为 17 秒。
  文案及图片 URL 可在 JSON 的 `materials` 中替换；每组已声明 dynamic：
  文字 content、图片 remote_url；片段时间默认不声明 dynamic。
  analyze/compile 返回 dynamicInputs 字段清单，调用方可用 modifications 替换；
  编译的 Workflow inputs 接收动态值，workflowInputBindings 指明对应变量及运行时支持范围。
  文字、图片可直接改 inputs 复用 Workflow；时间需手动声明 dynamic 才成为输入。
  页面时间轴仍展示默认值。
  当前页面未生成动态输入表单，仍使用 JSON 中的默认值。
  示例图片使用远程图片地址，测试导出需要联网；创建模版本身不会执行 Workflow。
- 混排演示：默认 16 秒竖屏 Scene，共两条逻辑轨道。上轨依次显示图片（0–4 秒）、
  文字（4–8 秒）、图片（8–12 秒）、文字（12–16 秒）；下轨文字持续 16 秒。
  同轨内容不重叠，层级树与时间轴显示上轨在前；Workflow 拆成上轨 video/text 两条、
  下轨 text 一条，共三条类型轨道，保留上轨高于下轨的层级。
  文字 1 的 start 自动关联图片 1 的 end，保留 4 秒时长；图片 1 改时间后文字 1 跟随。
  后续图片 2 仍从第 8 秒开始，若调整后与它重叠会报错，不自动移动后续片段。
  Scene 已开启 auto_duration，根没有固定 duration；最后一段文字改为 8 秒后，
  Scene 与总时长变成 20 秒，下层文字随 Scene 铺满，不需手动调整 Scene 时间。
  文案、图片地址默认标记 dynamic，上轨时间保留为静态配置，可直接测试编译与导出；
  图片使用远程图片地址，实际导出需联网，尚未验证真实渲染。

## 使用方式

- 默认每个文字/音频/视频/图片元素仅开放一个内容输入：`text`、`music_url`、
  `video_url`、`image_url`，值均为纯字符串，不携带颜色、样式或时间对象。
  输入按目录元素名称分组；生成时 key 和脚本引用均使用 ASCII 标识符。
  名称先规范化空格和标点，再将非 ASCII 名称转换为 `__label_` 加 UTF-8 十六进制编码；
  同一输入范围内重名依次追加 `_2`、`_3`。中文目录名称保存在
  `input_labels: [{"path": ["输入key"], "label": "目录名称"}]`，不参与脚本求值。
  保留字、与动作 ID 重名的名称加 `input_` 前缀；每个默认元素对象仍仅含一个内容字段。
  模版内部仍用剪映协议的 `content`、`path`、`remote_url` 声明 dynamic；
  文字 binding 的 `encoding: "text"` 表示从文字 JSON 中取 `text` 作为 Workflow 输入。
  新增元素和内置预设不默认声明时间 dynamic，手动声明的额外字段继续保留并按原规则处理。
- 顶部按钮添加 Scene、文字、图片、视频、音频及资源效果。媒体通过本地文件选择框添加。
  添加 Scene 不选文件、不创建素材，直接插入默认持续 5 秒的空组合，可继续递归嵌套。
  模版层未选中元素时添加 Scene，会接在顶层场景末尾；已有固定根时长会相应延长。
  时间轴末尾的“添加分镜”按钮仅在分镜内部显示，根时间轴不显示。
  在批量分镜内（其唯一子分镜被省略显示）添加任何素材都落入该子分镜，
  包装器轨道保持只含这一个子分镜。
- 批量分镜嵌套批量分镜时，Workflow 仅导出最外层批量数组。
  外层数组、内层列表与素材对象分别从目录名称生成 ASCII key，并用 `input_labels`
  保留“音画同步”、“文案配音”、“文案”、“配音”和“背景视频”等名称，更深层递归嵌套。
  普通组合不会额外产生列表，内层素材不重复展开到外层条目。

  ```json
  {
    "inputs": {
      "__label_e99fb3e794bbe5908ce6ada5": [
        {
          "__label_e69687e6a188e9858de99fb3": [
            {
              "__label_e69687e6a188": { "text": "第一段文案" },
              "__label_e9858de99fb3": { "music_url": "/absolute/path/voice.mp3" }
            }
          ],
          "__label_e8838ce699afe8a786e9a291": { "video_url": "/absolute/path/background.mp4" }
        }
      ]
    },
    "input_labels": [
      { "path": ["__label_e99fb3e794bbe5908ce6ada5"], "label": "音画同步" },
      { "path": ["__label_e99fb3e794bbe5908ce6ada5", "*", "__label_e69687e6a188e9858de99fb3"], "label": "文案配音" },
      { "path": ["__label_e99fb3e794bbe5908ce6ada5", "*", "__label_e69687e6a188e9858de99fb3", "*", "__label_e69687e6a188"], "label": "文案" },
      { "path": ["__label_e99fb3e794bbe5908ce6ada5", "*", "__label_e69687e6a188e9858de99fb3", "*", "__label_e9858de99fb3"], "label": "配音" },
      { "path": ["__label_e99fb3e794bbe5908ce6ada5", "*", "__label_e8838ce699afe8a786e9a291"], "label": "背景视频" }
    ]
  }
  ```

  内层循环读取当前外层条目的子列表，不使用独立的顶层共享数组；
  外层上下文在进入内层循环前保存，后续背景素材不会误取内层 `item`。
  批量时长在执行时遍历当前列表逐项累计；Auto 父分镜按完整子批次推导时长，
  自动填充到父级结束的背景视频覆盖全部子条目，而不是仅覆盖第一个。
  后续外层条目从上一组实际结束位置开始，不用固定单项时长乘 index；
  修改 inputs 列表数量无需重新编译。测量循环不执行素材动作，空 Auto 子列表贡献零时长。
  每项仍按模版的时间配置/媒体元数据计算时长，不会仅因 URL 更换自动探测新媒体时长；
  固定父级和根时长仍裁切最终可见内容。
  缺省子列表按子模版默认值补全，明确的空数组保留为空；非数组子列表拒绝编译。
  重新编译时兼容旧版 `title`、`text: {text: ...}` 与 `audio/video/image: {url: ...}` 条目，
  以及 `scenes` 子列表，并转换为按目录名称分组的字段。
  新批量分镜默认条目为 `{}`，仅按实际元素补全输入，不导出不存在的 `image` 等历史占位。
  `workflowInputBindings` 中嵌套输入的 `variable` 指向最外层变量，
  `inputPath` 标明相对路径，例如 `["*", "__label_e69687e6a188e9858de99fb3"]`，`*` 表示数组条目；
  普通素材的 `inputPath` 指向对象内的唯一字段，例如 `["text"]`。
  测试执行边界也兼容旧中文 key 的 Workflow，递归转换变量和路径，字符串内容保持原样，
  支持重复适配且不修改原对象；新生成的 Workflow 无需等到执行才转换。
  实际后端和渲染仍需单独验证。
- 根层仍只存放 Scene，不支持根层基础元素或 tracks。
  在 Scene 内，单击子 Scene 只选中该片段，双击才进入其内部。
  顶部添加按钮选中普通片段时在其所属 Scene 新建同级轨道，不追加到片段所在轨道。
  选中 Scene 容器时向其内部添加；明确选中轨道时才在同轨末尾追加，
  并关联上一片段的结束，支持不同类型在 mixed 轨道连续出现。
  在模版范围添加基础元素仍进入选中元素所属 Scene，未选中时使用第一个 Scene。
  添加成功后自动进入新元素所属 Scene，展开层级并选中新元素；
  新增顶层 Scene 仍停留根层，取消或失败不切换范围，撤销恢复添加前的范围。
- 在 Scene 内未选中轨道，或选中普通片段时添加素材，会创建新的最上层 mixed 逻辑轨道，
  target_timerange.start=0；固定 Scene 省略 duration，默认延伸至 Scene 结尾，
  auto_duration Scene 新片段明确默认持续 5 秒，以便内部内容可以决定 Scene 长度。
  进入子 Scene 后，新增内容进入该子 Scene，而不是根 Scene。
- 明确选中轨道后添加，会接在该轨已有片段末尾；固定 Scene 剩余时间不足报错，
  自动 Scene 则根据新增的明确时长继续延长。
  可混排不同类型，但同轨可见区间不能重叠，不能用多行隐藏冲突。
- 只编辑一个 Template JSON；素材在 materials、时间关联在 `auto_timing` 中。
  不使用旧 elements、独立 timing_rules 或 sources 配置。
- Scene 内拖动片段时显示跟手浮动预览；轨道中部高亮落点，轨道边界蓝线表示插入新轨道。
  松手才提交 `move-clip`：现有轨道内按前后半区插入并顺延冲突片段，自动填充文字或图片
  可收至下一段开始；跨轨后清理原空轨并重新编号。边缘裁切仍使用 `retime`，不触发插入。
  Escape、指针取消或锁定轨道落点不会提交；原地落下不产生历史记录。
- 拖到子 Scene 组合片段上时该片段高亮为容器落点，松手提交 `move-into-scene` 并进入该
  Scene：片段按当前视图坐标换算为 Scene 内局部时间，按前后半区规则插入 Scene 内
  mixed 轨道（无合适轨道时新建），被挤开的片段顺延；原轨清空后自动删除，原轨后续
  跟随者改挂前驱。分镜不能移入自身或其内部嵌套的分镜；成功后视图切到目标 Scene。
  批量分镜同样可作为容器，实际落点重定向到其唯一子分镜，包装器结构保持不变。
- 右上角花括号按钮切换 Workflow 视图，再次点击返回 JSON。视图内容可直接编辑：
  编辑后仅保留在当前视图，模版 JSON 与时间轴不变；切回 JSON、切换节点或修改模版会丢弃编辑。
- 右侧“测试导出”编译当前文档、执行 Workflow，然后将返回的草稿提交到主窗口下载队列。
  Workflow 视图有编辑内容时直接执行当前内容，否则执行重新编译的结果。
  按钮期间禁止重复提交；入队不是下载完成，最终进度与失败信息在主窗口查看。
  执行成功但导出入队失败时保留草稿 ID，再次点击同一文档只重试导出。
- 点击层级节点或时间轴片段，会选择对应元素并在 JSON 中定位。
- 左侧只列 Scene 和素材元素，不再插入轨道目录节点。
  目录行可拖动：行的上半/下半表示插在目标之前/之后，分镜行的中部表示移入内部。
  拖动显示半透明来源、上下插入线或容器高亮，悬停折叠分镜 550ms 自动展开，
  靠近目录上下边缘自动滚动。根分镜也支持拖动，禁止基础素材进入根层、分镜进入自身后代。
  目录拖动提交 `move-layer`，调整的是视觉层级，不使用时间轴的插入顺延规则；
  同轨素材需要时拆成独立轨道，保留素材起止和源裁切，跨父级的失效兄弟时间引用固定为原时间。
  拖入批量分镜落到唯一子分镜，原空轨清理；锁定轨道不接受拖动。
  松手后自动选中来源元素并展开/显示新的所属分镜，支持撤销和重做；取消拖动不修改 JSON。
  左侧分组线按所选节点所属 Scene 的真实轨道划分：同轨元素及其展开后代共用连续蓝线，
  其他轨道为灰线，只有选中行显示蓝色背景。进入内部元素选择时按该层轨道重新分组；
  折叠、展开和换轨后端点随可见目录更新，不按名称或素材类型归组，也不新增行外边框。
  分镜与批量分镜在折叠箭头后分别显示 Lucide Layers、LayersPlus 图标。
  Scene 箭头控制树的展开，不切换底部范围；双击名称重命名（包括批量分镜），双击 Scene 行的其他区域
  或对选中的 Scene 按 Enter 进入其内部时间轴。
  面包屑可返回任一祖先，Escape 返回上一层；元素右键“在时间轴中显示”定位其所属 Scene。
  上下方向键选择相邻节点，左右键折叠/展开；F2 或右键重命名，Delete 删除。
  有其他元素时间引用的对象不能直接删除，错误时保留原文档。
- 同一逻辑轨道只显示一行，图片/文字/音频/视频图标由实际素材决定；空轨保留。
  子 Scene 在父轨道显示组合片段，双击进入内部轨道；整个组合区间占用父轨道，
  内部空白也不能与同轨其他片段重叠。
  层级树和时间轴均按逻辑层级降序显示，数字越大越靠上。
  轨道内子 Scene 的内部层级带嵌入父轨道位置，位于父级上轨之下、下轨之上；
  兼容旧 Scene.scenes 写法时，其轨道带仍位于父 Scene 的全部轨道之后。
  转 Workflow 才拆成类型轨道并补偿后台层级，不在编辑视图显示拆轨结果。
- 时间轴轨道标签可点击选择轨道，JSON 会定位到该轨道对象。
- 时间轴只显示当前 Scene 的直属轨道，使用该 Scene 内部的局部声明时间。
  超出 Scene 结尾的部分位于斜纹区；最终可见区间和导出仍由祖先裁切规则决定。
  祖先完全裁掉某个子 Scene 时，编辑分析仍递归保留其内部片段的局部时间，
  进入该分镜后可查看、添加和调整内容；不会自动延长固定父级或改变导出裁切。
- 无效 JSON 保留当前输入，层级保留上次有效结构，时间轴暂停展示，
  禁止添加素材及编译；修正后自动恢复。输入变动会清除旧 Workflow。

## 时间轴编辑

- 拖动片段改变开始时间，拖动两端改变区间；同一 Scene 内可拖到另一轨道。
  松手才调用 `template:editor-edit`，在文档副本上完整校验后提交；冲突失败恢复原状态。
  拖动期间只绘制片段预览，不逐帧调用 IPC；Escape 或 pointercancel 取消本次拖动。
- 默认吸附其他片段边缘、游标、Scene 末尾。Ctrl/Cmd 临时取消吸附，Alt 按 0.1 秒对齐。
  片段左右方向键移动 0.1 秒，Shift 加速到 1 秒。
- `auto_timing` 锚点优先通过 offset 调整，不悄悄删除关联。整体移动双端关联片段时，
  两个锚点一起调整；左端裁切有源区间的媒体会同步推进源起点。
  当前 parent 锚点的限制仍适用，无法表达的修改会报错并保留原状态。
- 调整自动 Scene 的边缘会切换为固定时长。标尺末尾手柄可以拖动或点击输入时长，
  也可选择“自动”恢复按内容计算；空 Scene 不能使用自动时长。
- 片段两端的 Pin/关联/自动时长图标可打开同一时间设置浮层，外缘仍用于裁切。
  开始支持固定时间、跟随同轨上一片段、与父结束对齐；时长支持固定秒数和自动。
  Scene 自动时长由内部内容决定，基础素材自动时长延续到所属 Scene 结束，
  不探测媒体的实际源时长。结束对齐需要固定时长，不能同时选择自动填充。
  时间输入接受 HH:MM:SS.xx、MM:SS.xx 或秒数，按整数微秒写回；
  仅显示时四舍五入至百分之一秒。支持整段复制粘贴，点击数字选中对应时间段，
  左右方向键切换时间段，上下键增减该段数值，Enter/失焦提交。
  `clip-timing` 在主进程副本上校验后提交，支持撤销、锁定、失败保留原文档。
  自动规则覆盖已声明的数值时间输入时，保留其默认值以避免 dynamic 引用失效。
- 视频/音频额外显示“媒体”时长。`duration_mode: "media"` 按
  `source_timerange.duration`、`source_timerange.end - start`，或素材的整数微秒
  `duration - source_timerange.start` 推导；不把目标时长误作源时长，缺元数据时禁用。
  批量分镜开启 Auto 时，添加内容或调整内部片段时间会同步启用隐藏子分镜的
  内容时长推导；切换 Auto 的两个入口同样联动，媒体变长或变短后整体随之更新。
  固定时长的批量分镜仍按指定边界裁切，不被媒体时长自动延长。
  手动调整边缘或固定/自动时长会退出媒体模式。
  视频/音频时长弹窗提供“循环”开关，提交 `clip-loop` 写入 `loop: true/false`，可撤销/重做。
  循环不改变目标区间或媒体模式；固定/自动目标时长超出源区间时，从源截取起点重复，
  最后一轮裁切至目标结束。媒体模式仍是一轮源时长，不会无限延长 Auto 分镜。
  源长度沿用媒体模式的整数微秒规则；缺元数据时禁止开启，导出缺少源长度的循环会报错。
  父级左裁切保留循环相位。静态 Workflow 展开重复动作，动态 Workflow 使用数字 `loopCount`，
  内层批量循环的上下文不会被媒体循环覆盖；单片段超过 10000 轮明确报错。
- 轨道左侧拖动手柄调整上下层级；左侧树中把元素拖到同 Scene 的另一轨道元素位置，
  同样调整所属轨道层级，不将元素移入其他 Scene。
- 锁图标仅锁定当前窗口的编辑操作，不表示隐藏，不写入导出内容。
  当前未实现轨道隐藏、关键帧轨道编辑和多选；跨 Scene 拖动仅支持拖入子 Scene
  容器，不支持任意两个 Scene 之间互相拖放。
- 层级树与时间轴支持 Ctrl/Cmd+C 复制选中的元素、分镜或轨道，Ctrl/Cmd+V 粘贴。
  分镜递归复制内部内容，元素与素材使用新的 ID，内部时间关联改为指向副本；
  指向复制范围外的时间关联转换为解析后的父级固定偏移，素材路径和格式保持不变。
  普通元素在所属分镜创建同级轨道，分镜在同级新建轨道；根分镜追加到根末尾。
  无选择时粘贴进入当前分镜，基础元素不能直接放在根层，根层默认使用第一个分镜。
  系统剪贴板保存复制时的快照，源元素修改或删除后仍可粘贴，也支持跨编辑窗口。
  粘贴后自动展开并选中副本，可撤销/重做；锁定目标禁止粘贴。
  名称、时间输入框和 JSON 编辑区仍使用系统的文字复制粘贴，不触发元素操作。
- 可拖动标尺游标、输入精确秒数、缩放并横向滚动；轨道标签与标尺固定。
  时间轴顶部的分隔线可拖动调整高度。
- 顶部撤销/重做记录 JSON 修改及视觉编辑，最多 100 次；Ctrl/Cmd+Z 撤销，
  Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做。普通名称/时间输入保留系统输入框自身的编辑行为。
  撤销不重发导出，也不影响已经提交的服务端任务。

## 当前范围

- 图片与文字可转换为 Workflow，视觉适配仍遵守现有编译器的警告。
- 轨道内 Scene 递归展开为内部媒体动作，不生成剪映原生复合片段。
  Scene 整体变换暂未适配，整体变速、源裁切和隐藏明确拒绝；关键帧保留但阻止 Workflow 导出。
- 视频、音频目前仅支持 JSON 编辑和时间编排，不解析源媒体时长，不转换为 Workflow。
  包含这些元素时整次转换明确失败，禁止跳过它们输出不完整结果。
- 编辑状态仅保留在当前窗口，尚未接入保存或恢复。仅主动点击“测试导出”才执行 Workflow。
- 测试导出使用现有登录凭证与服务端接口，可能产生正常的服务消耗；不会自动重复执行失败请求。
- 界面 JSON 保持普通字符串；执行边界使用 inputs 变量引用保护文字、颜色和路径，
  防止后台把文字中的算式、引号或变量符号误作表达式。
- 文件选择不上传媒体，使用本地路径；远程后台访问素材仍需自行映射或上传。
- 时间字段为整数微秒 target_timerange/source_timerange，旧 time 等字段不接受。
  主进程更新后需重启应用；逻辑层级映射改变后需重新编译 Workflow。

## 代码与验证

- `editorModel.ts`：数据解析、层级、轨道布局、添加素材、编译调用。
- `editorActions.ts`：重命名、删除、移动、裁切、轨道排序及 Scene 时长的事务式编辑。
- `editorClipTiming.ts`：片段开始/时长规则切换；`ClipTiming/`：图标、时间输入和独立浮层。
- `draftTracks.ts`：混排类型识别、时间冲突校验、统一层级和剪映类型拆轨。
- `sceneTiming.ts`：分析与动态 Workflow 共用的关联解析和内容时长推导。
- `dynamicInputs.ts`：剪映字段的动态输入发现、类型检查及副本替换。
- `dynamicWorkflow.ts`：动态输入映射、变量引用、运行时时间关联与可见性分支。
- `sceneTemplate.ts`：共用时间语义；analyzeSceneTemplate 只解析时间，
  compileSceneTemplate 才校验素材和生成动作。
- `registerTemplateIpc.ts`：编辑器 IPC 与系统文件选择框。
- Page 只负责交互与展示，通过 IPC 调用主进程模型。
- `LayerPanel.jsx` / `EditorTimeline.jsx`：元素目录和当前 Scene 时间轴交互。
- `editorView.js`：层级索引、局部时间轴和像素阈值吸附计算。
